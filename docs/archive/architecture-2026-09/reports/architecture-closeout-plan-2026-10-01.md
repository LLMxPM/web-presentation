## 5 工程阶段必做场景

### M04 构建与 AI 外部交接

1. **构建 attempt**：真实执行中强杀、租约过期/回收、旧 attempt 晚到上传、取消与完成竞争。当前 attempt 才可提升产物；页面版本复核生效，过期产物不覆盖或删除已提升产物，子进程/临时文件/额度释放。
2. **认领与额度**：多个独立 Job 在双执行副本竞争，实际达到全局和工作空间预算。保存不同 Job/Attempt/Worker ID 与额度快照；确认不超限、等待/拒绝可解释、终态后可再领取。正常任务数多不等同饱和验证。
3. **活跃与交接保护**：A 失效/扫描期间保持 B 静默但正常执行，覆盖 paused、waiting_external、有效 resuming Batch 租约及取消竞争。收敛器不能误杀，失效执行不能借旧 owner 或旧 Batch 围栏提交。
4. **Batch 一次消费**：页面、图片和组件任务在同 step 封口，覆盖成功、失败、取消和供应商等待；双协调器竞争下全部终态只恢复一次。`waiting_provider` 使用合法 `next_poll_at`，不占执行租约；resolving Requirement 匹配有效 resuming 租约；消费后完整 Task result 清空。
5. **摘流与回收**：Worker 摘除前运行现有只读检查；检查实际进程、僵尸、临时产物、租约和槽位。截图已通过场景按差异复用，执行生命周期变更后定向重跑。

外部模型/图片供应商可用受控服务生成确定响应，但领域入队、租约、轮询、取消、渲染与自动续跑必须走生产路径。受控模型结果不能证明真实供应商的可用性或延迟。

### M02 文件 token 与网络边界

对可信领取器、编译/检查子进程和 Renderer 浏览器分别记录允许/拒绝矩阵：全局凭证文件与父进程环境、自己的任务目录与其它任务目录、只读应用目录、自己的任务 token 与其它 job token、Backend 控制 API、Renderer 控制 API 和非必要网络目标。补缺失、空凭证、过期票据及跨任务越权负例。

当前共享 UID/GID 10001 与组可写任务目录只证明全局凭证降权，不证明任务间文件隔离。实测不成立的已承诺边界必须修复并复测；沿用 Lite 已接受的受限形态，不新增生产多租户隔离承诺。构建/检查取消、期限与异常退出均要求子进程及僵尸消失、目录/槽位释放。

### M07 完整系统恢复

SQLite 与 PG 各准备一套独立恢复目标。固定样本包含既有账号、工作空间、页面、上传资源、截图、构建 ZIP 和一条可解密模型凭证；备份绑定 schema、镜像、配置与密钥，并通过停写或一致快照保证备份集一致。

本轮内部恢复目标采用 **RPO 不超过 24 小时、RTO 不超过 2 小时**，这是演练验收目标，不是新增对外 SLA。记录备份恢复点、模拟事故时间、恢复开始和完整业务通过时间；恢复数据与备份集一致，备份后的缺失写入显式计入 RPO。

恢复后实际验证登录、读页、资源下载、模型凭据解密、预览、真实 PNG、ZIP 下载与入口加载。错误密钥、缺资源、错误版本、校验和不匹配必须清晰失败。只恢复到本轮目标，不进行生产在线一致备份体系重建或生产数据修复。

### M08 用户行为与跨仓回归

验证资产筛选/详情/批量、AI 进程停止文案与会话重新发起、富文本自闭合节点不绑定写入与成对空节点可编辑、诊断降级不使整页失败。跨用户工作空间写入必须拒绝；Internal 与 External 两入口覆盖读取、写入、异步任务及归档。

固定同级 Agent Kit 的 Git ref、配置与契约版本，跑真实 CLI/Skill 典型路径。只修本轮变更导致的兼容缺陷，不顺带扩展 CLI/MCP 功能。保留真实 E2E 报告、截图与两仓版本；类型检查不代替行为证据。

| 业务 | 基准到达率 | 端到端 P95 目标 |
