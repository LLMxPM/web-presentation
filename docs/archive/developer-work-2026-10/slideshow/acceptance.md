## 1. 验证层次与数据

- Backend 单测/API 测试验证配置合法性、事务、权限、迁移、幂等和模板往返；共享样例约束 API 与 Runtime 数据转换。
- Editor 测试验证草稿、继承/null、生成类型、提交与错误反馈；Runtime 虚拟时钟验证调度和旧回调失效。
- 真实浏览器验证 CSS 过渡、媒体、全屏、双窗口和可见性；远程截图必须检查实际 PNG，导出必须检查实际文件。
- 准备独立 fixture：可见封面、分组子页、隐藏页、同一页面重复引用、末页；另有无视频、单视频、多视频、循环背景、失效资源和延迟加载页。
- 验证使用不可变 artifact/snapshot，记录项目默认与路由原始覆盖；E2E 使用技能规定的隔离库和 mock 环境，不重置开发数据。

## 5.1 全屏放映统一模型补充（2026-10-18）

| 编号 | 场景 | 通过条件 |
| :--- | :--- | :--- |
| F01 | 预览与进入/退出全屏 | 预览无控制器、无控制条、无自动计时；进入全屏即开始放映；退出全屏停止计时和媒体并回到预览；全屏失败留在预览并提示 |
| F02 | 自动/手动切换 | `auto_start` 决定初始模式；自动切手动取消计时但媒体继续；手动切自动按当前页重新计时/等待媒体；`manual` 页不自动推进；手动末页不绕回 |
| F03 | 全屏控制条与键盘 | 控制条提供上一页/自动手动/下一页/页码/状态/剩余时间/演讲/退出，默认收起、指针进入底部区域显示、移开隐藏，暂停/错误/结束态保持显示；预览与放映均支持 `→`/`↓`/`PageDown`/空格下一页、`←`/`↑`/`PageUp` 上一页、`Home`/`End` 首末页、数字键跳页；预览另有 `O` 卡片模式、`F` 进入放映、`Shift+P` 演讲，放映保留 `Shift+P`；无双重触发；不拦截 F11，F11/浏览器菜单全屏不进入放映 |
| F04 | 演讲者模式 | 观众窗口唯一调度；预览工具栏或放映控制条均可进入，预览入口按项目 `auto_start` 起步、放映入口继承当前模式；必须全屏后才开始；观众只读；控制台传输栏切换自动/手动并同步；退出全屏暂停并提示；控制台键盘不受观众全屏门禁限制，重开观众窗口按项目 `auto_start` 初始化 |

自动化证据：Runtime 全量 143 个测试文件、1121 通过、3 跳过（`pnpm --dir runtime test`），`pnpm --dir runtime check` 与改动文件 ESLint 通过；覆盖虚拟时钟自动/手动语义、媒体继续、控制条命令、预览/全屏布局归属、工具栏按钮聚焦时方向键翻页、协议 v3 与观众全屏门禁。

真实桌面 Chromium 证据（2026-10-18，有头 Chromium 148.0.7778.96 / Playwright 1.60.0 / Windows 10.0.26300 x64 / 1280×720）：`node .tmp/fullscreen-playback/verify.mjs` 通过 38/38 项，覆盖 F01–F04。关键结果：预览无控制条且 1.8s 内不推进；进入全屏即开始会话并显示自动剩余时间；自动切手动停住、切回自动按当前页重新计时后翻页；手动配置页显示“本页手动”且会话仍为自动；空格在自动/手动间切换，方向键翻页，工具栏按钮聚焦后方向键仍有效；退出全屏控制条消失且无后台推进，重新进入从当前页开始；演讲者模式观众窗口唯一调度，继承手动模式，控制台切换自动后观众按 1500ms 推进，切回手动后停住，观众键盘不翻页；观众退出全屏后控制台等待重新全屏、播放保持暂停，重新全屏后“继续”恢复；退出演讲回预览且无残留控制条。证据为 `.tmp/fullscreen-playback/evidence.json` 与截图 `01`–`09`。未验证：观众窗口 `getScreenDetails` 多屏授权（使用“当前窗口全屏”回退）、Firefox/WebKit、移动端；旧 M3 长稳不作为全屏入口证据。

键盘口径更新（2026-10-18，晚于上方浏览器证据）：放映态空格改为下一页，新增 `Home`/`End`、数字键跳页、`↑`/`↓` 翻页、`O` 卡片模式与 `F` 进入放映；键位集中在 `runtime/src/runtime-shell/keyboard/keyboard-map.ts`，`usePlaybackHost` 不再注册键盘监听。该变更由 `keyboard-map`、`ResponsiveLayout`、`usePlaybackHost` 单测与组件测试覆盖，未重跑上方真实浏览器脚本；“空格在自动/手动间切换”一条为变更前记录。

文档口径与已知行为（2026-10-18 复核）：F11/浏览器菜单全屏不写 `document.fullscreenElement`，不进入放映，也不被页面拦截；页面内元素全屏期间放映继续，退出该元素全屏后 Chromium 不恢复根全屏，按退出全屏结束并回预览。这两项属于实现行为，本轮未单列浏览器用例；观众窗口重开不继承临时模式、控制台键盘不受观众全屏门禁限制为设计意图，详见[全屏放映统一模型规划](fullscreen-playback-plan.md) §12。控制条悬停唤出由组件测试覆盖（`PlaybackHostBridge.test.ts` 5 项通过），未重跑上方真实浏览器 38 项。

| 新 Backend + 旧客户端 | 可读取新增字段；匹配节点整树更新保留覆盖；新模式需能力检测 |
| 新客户端 + 旧 Backend | 新参数返回明确不支持或校验失败，不能伪装保存成功 |
| 新 Backend 配置 + 旧 Runtime 执行池 | 不验收为支持；发布前升级配套 Runtime 或阻止开放新能力 |
| 新模板导入器 + schema 1/2/3 | 三版本均接受，旧包补默认；schema 3 保留原始覆盖 |
| 旧模板导入器 + schema 3 | 明确拒绝，不静默丢失放映字段 |

配置快照、Runtime 构建身份和能力版本一起记录；已有历史 artifact 不重写。发布前完成迁移备份、同版部署验证和回滚说明，旧应用回滚不等于新模板/新配置可被旧版本完整编辑。
