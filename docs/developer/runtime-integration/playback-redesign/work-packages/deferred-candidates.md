# 推迟候选（不阻塞 GC）

状态：推迟。这三项都不是本轮交付内容；写在这里是为了明确「推迟不等于放弃」，并固定各自的启动条件，避免后续被当成遗漏重新争论。

## D1 动效目录化

把动效从「页面写 GSAP 代码」变成「平台拥有的可枚举资产」：

- 入场、强调、退场、翻页过渡作为版本化 Runtime Kit 资产；页面与组件只声明「目标元素 ＋ 效果名 ＋ 参数 ＋ 顺序或触发」。
- Backend 可静态校验声明与默认静态态；编辑预览通过真实正向播放观察效果。目录效果不提供局部任意进度截图、状态证明或页面级时间轴取帧。
- 截图与静态交付继续使用 B0 定义的默认态或显式海报态，不把效果进度写入截图身份。
- 主题可指定默认动效风格；工作空间组件可声明动效（本轮组件不纳入 Scene 的缺口由此补上）。
- AI 从目录选效果而不是写 GSAP，CodeCheck 能校验声明、参数与静态态；动态效果仍需真实正向放映验收，不把静态截图解释成中间态验证。

设计要点：表达力靠**扩展目录**增长，不靠页面代码增长；效果之间可叠加，但不提供可编排的全局时间轴。首批效果清单应从 PPT 语义收敛：淡入、飞入、擦除、缩放、逐条列表出现、数字滚动、图表绘入。

启动条件：A/B/C 三段完成且放映可靠后；或 A1 的缺口清单实测确认「AI 生成动画无法验证」已成为真实瓶颈。

## D2 高级 Three.js 实例扩展

为页面代码提供限定在单个模型实例内的对象树、相机、材质与逐帧回调接口，支持材质变化或骨骼控制。开放前必须明确材质与几何体的实例拷贝或写时复制规则、实例级分配、重绘、上下文丢失恢复与 `onCleanup` 释放——当前缓存共享几何/材质，直接把共享对象交给页面会让同资源其它实例串色或串动作。静态捕获不运行逐帧回调。若引入 Shader、Worker 或解码依赖，必须先进入构建与资源预算并明确许可。

启动条件：出现真实用例；至少两个实例共享同一 GLB 时互不污染，退出/切页后 GPU、RAF 与监听释放，真实 WebGL 与独立构建产物验证通过，再决定是否写入正式 manifest。

## D3 产品级无人值守放映

远端代理服务、访问入口与票据续签、代理层、kiosk 入口。slideshow M3 已将其移出范围，本地构建产物放映是当前承诺的边界；全屏入口的无人值守时长也未重新累计（旧 61 分钟长稳是窗口化自动开始，不能作为全屏放映证据）。

启动条件：出现真实的无人值守部署需求。

## 不在规划范围（非推迟）

- **任意时刻状态重建**：永久放弃，见[规划第 4 节](../../playback-redesign-proposal.md)。不以任何形式恢复，包括「只给 AI 诊断用的取帧」或 D1 目录效果的局部进度截图。
- **Three.js 对象树粒子**：页面粒子效果用 DOM、CSS 或 Canvas 自行实现。
- **GSAP 插件**：不支持；导入校验与 CodeCheck 拒绝插件用法。
- **混版与回退矩阵、B01–B08 模型创作量化门槛、组件独立轨道片段预览**：作废。
