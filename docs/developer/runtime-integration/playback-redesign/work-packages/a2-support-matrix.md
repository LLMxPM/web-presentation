# A2 支持矩阵与降级边界

状态：待实施。主责：Runtime / 跨模块验证。前置：[A1](./a1-joint-playback.md)。出口：GA。

收敛的一部分是明确**不支持什么**。本包把长期悬空的边界项一次性验证或显式排除，产出支持矩阵。

## 交付

- 演练 WebGL 上下文丢失/恢复：播放中的模型页触发 `WEBGL_lose_context`，验证恢复或明确错误、实例互不影响、无重复播放者（承接 G2-07）。
- 以现有 v4 协议演练 BroadcastChannel 不可用时降级 localStorage、后台节流、观众窗口关闭与重开、退出全屏后的状态收敛，作为 B5 精简协议的真实基线（承接 G2-08）。A2 不宣称已验证尚未实施的新协议；B5 必须复验新协议的意图传递、原子状态、旧 revision 拒绝与重开对齐。
- 用真实受保护端点与受控慢速传输复现媒体 `waiting` 与恢复（承接 G2-11），为 B4 的新所有权提供基线。
- 验证或明确排除：观众窗口 `getScreenDetails` 多屏授权（现有脚本用「当前窗口全屏」回退）、Firefox/WebKit、移动端。不验证的必须写进支持矩阵为不支持，不留空白。
- 输出支持矩阵：浏览器、窗口拓扑、屏幕数量、部署形态、放映入口（Editor 预览 / Runtime 全屏 / 构建产物）各自的支持状态与已知边界。

## 验收

每条演练有真实浏览器证据与复现步骤；未验证项显式标注，不把「未测」写成「通过」。支持矩阵草稿在本包产出，正式落地到用户文档由 C2 完成。
