# A2 契约责任与验收设计

状态：完成（2026-10-29，验收设计）。主责：Runtime / 跨模块。前置：[A1](./a1-joint-playback.md)。出口：GA。

本包把跨包责任和最终验收输入准备好，使 B 段可直接进入实现。支持范围先写目标与待验证状态；原实机演练移至 C3，旧 Presenter v4 已随 B5/C2 删除，不补跑其基线。支持矩阵草稿由 [C2](./c2-legacy-zero.md)整理为可回填表格，最终结论由 C3 实测后写入。

## 交付

- 列出契约责任与交接：B0 定静态声明、执行上下文和就绪回执；B2 定 Scene 生命周期、任务标记、完成、时序和取消；B3/B4 定模型与媒体句柄；B5 定配置 DTO、Presenter 意图/状态与各调用端。复用总规划，不另造第二套协议；具体类型与路径由责任包实施时冻结并同步消费端。
- 定义同一端到端样例：DOM 多序列、数字滚动、打字机、SVG 描边、页面粒子、两个模型动作、旁白、静音视频、无限装饰与切页 cue；为各项声明静态态和预期完成条件。B2/B5 准备源码与负例，C3 用正式入口执行。
- 将原 A1/A2 和旧 G2 遗留项映射到 C3：联合创作、镜像三角色、独立 ZIP、真实发声、Renderer 取消、受保护媒体慢传输、WebGL 丢失/恢复、多窗口降级与后台节流、长稳指标；逐项明确预期、证据和失败承接包。
- 输出支持矩阵草稿：浏览器、窗口拓扑、屏幕数量、部署形态及 Editor 预览 / Runtime 全屏 / 独立产物入口，区分目标支持、待验证和明确不支持。多屏授权、Firefox/WebKit、移动端未验证前不宣称支持；实际结论在 C3 回填。
- 盘点可复用的测试、素材和脚本；划清逐包开发测试与 C3 实机清单。新协议需要的自动化夹具随责任包实现，C2 检查可执行入口，C3 正式运行；不为已放弃的旧能力补新门禁。

跨包契约无无人负责的字段或重复所有者；共同样例、开发测试映射、支持矩阵草稿与 C3 实机证据清单齐全。文档与相关契约检查通过后进入 B0；本包不执行实机验收，支持矩阵实际结论由 C3 回填到 C2 准备的用户文档。
