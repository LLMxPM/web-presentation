# B0 静态呈现契约与默认截图替代

状态：完成（工程与开发测试，实机待 C3）。主责：Runtime / Renderer / render-contracts / Backend。前置：[A2](./a2-support-matrix.md)。出口：GB 的前置门槛。实现与验证见[开发记录](../development-record.md#b0-独立静态呈现2026-10-29)；稳定契约见[独立静态呈现](../../../runtime/static-presentation.md)。

本包先让默认截图脱离时间轴采样，再允许 B1 删除指定时刻取帧。现有默认海报由 `poster.atMs/atLabel → sampleAt` 实现；直接删除采样器会破坏已经运行的 PNG、缩略图与 PDF/PPTX。B0 保留现有放映 Transport，不改变正向播放行为。

## 静态契约

- 新增与播放时间无关的静态呈现模式：页面默认态可读时直接使用；否则作者显式提供海报态（可由页面代码渲染，不要求预先上传图片）。现有时间轴页面和后续 Scene 页面必须声明默认态、海报态或明确的 `unsupported`，Runtime 不从 GSAP、CSS、Canvas 或任意页面脚本猜测「是否可读」。不含受托管动画的页面继续沿用普通静态渲染。
- 本包冻结版本化 Runtime Kit 静态声明入口、manifest 路径、执行上下文与就绪回执字段；公开 import path 遵守 `.vN`。静态声明独立于 `usePageTimeline.v1` 和后续 `usePageScene.v1`，使 B2 替换播放入口时不必再次改截图契约。
- 静态模式不创建或启动播放会话，不调用受托管回调，不播放音视频、cue 或模型 Mixer。页面自有的 mounted 副作用、CSS/Canvas 动画不受 Scene 生命周期自动约束：创作契约要求它们提供静态分支，CodeCheck 只校验可声明、可观察的边界，不承诺阻止任意 JavaScript 副作用。
- 视频采用显式 poster 或有界首帧，模型采用声明的初始静态姿态；字体、图片、视频帧和模型首帧按既有就绪期限等待。海报态到放映起点的视觉交接由页面设计，不通过时间轴定位生成。
- Runtime 对目标画布返回有界静态就绪回执：`ready`、`unsupported` 或 `failed`，附稳定原因码。`unsupported` 只来自明确声明或静态契约缺失；资源失败、超时和执行异常归 `failed`。Renderer 只在 `ready` 时发布成功图片，不用图像启发式判断可读性。

## 交付

- 默认远程 PNG、写入时附带截图、缩略图与离屏 PDF/PPTX 导出统一使用上述静态态。捕获技术可以不同，视觉状态与就绪语义必须一致；清除导出中「把有限文档动画推进到终态」与 Renderer 静态默认态之间的分歧。
- 保留截图队列、同 attempt 诊断附图、受保护产物、输入指纹、版本/租约/取消围栏和默认截图指针。默认路径改为静态态，不再通过 `poster.atMs/atLabel` 采样。B1 前仍可暂留旧播放内部的 `sampleAt` 与编译器，不作为默认截图入口。
- 静态不可呈现是内容能力结果，不能复用任务 `skipped`：独立截图任务以不可重试的 `STATIC_PRESENTATION_UNAVAILABLE` 失败，附带截图仅标记图片阶段不可用而保留已成功的布局诊断；写入结果区分 `unavailable` 与 `pending/skipped`。任务过期、预算不足、未请求图片继续使用各自现有原因码。
- 缩略图显示标明原因的占位；PDF/PPTX 默认整体失败并指出页码与原因，不静默缺页。若以后提供「带占位继续导出」，必须由用户显式选择并在产物中保留占位说明。
- 截图身份继续覆盖源码闭包、引用资源、主题/字体、页面静态配置、视口/DPR、Runtime/Renderer 与捕获策略；模型身份包含资源版本、相机/光照/背景、初始姿态与尺寸。`transition`、`advance`、`playback` 与运行进度不进入静态像素身份，路由仍按现有可达性门控和页码目录投影纳入。

## 开发验收

- 单测、无浏览器集成测试、类型与契约测试覆盖各出口统一选择静态态，默认路径不调用 `sampleAt`；保持默认截图、附图、缩略图和 PDF/PPTX 的接线与开发回归，不允许已知接线错误拖到 C3。
- 覆盖可读默认态、显式海报态、`unsupported`、非受托管动画页面，以及静态分支、就绪回执、资源失败和零播放调用；不能靠等待动画结束生成静态态。
- 验证 `unsupported`、资源失败、任务过期和附图预算不足返回不同原因；布局诊断成功而图片失败时仍可保存诊断，截图版本围栏与默认指针不退化。

## 移交 C3 的实机验收

同一页在默认远程 PNG、写入附图、缩略图、PDF/PPTX 中呈现相同的可读静态内容；非零时间轴海报替代后仍可读，且不发声、不推进 Mixer、不执行受托管回调。真实浏览器和 Renderer 还须验证页面自有代码的静态分支、资源就绪及失败、不可呈现页的占位和整体导出失败。上述证据统一在 C3 取得，开发替身不能作为真实截图或导出通过证据。
