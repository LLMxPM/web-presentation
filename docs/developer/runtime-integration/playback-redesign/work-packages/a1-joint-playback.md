# A1 真实放映联合贯通

状态：待实施。主责：跨模块验证。前置：无。出口：GA。

本包不改内核、不删旧接口，用现有能力把四条线贯通成一次真实放映。它是 motion G2 关闭条件的重排，也是 B 段范围与 D1 启动条件的唯一依据。

## 交付

- 用现有 motion 时间轴、slideshow 全屏放映、audio 旁白与 cue、threejs 模型能力，跑通一次完整放映，记录实际使用的接口与配置。
- 从当前源码重建生产依赖裁剪的 Runtime 镜像：preview/check/build 三角色真实启动并通过健康检查，`__runtime_version`/`__runtime_readyz` 与 Runtime Kit 版本一致，不以开发依赖补齐（承接 G2-02）。
- 同一受控工作空间、同一样例页（DOM 动画 ＋ 模型 ＋ 旁白 ＋ 切页 cue），分别经 Editor 预览控件、内置助手与 CLI 完成：读取能力 → 创建/修改 → 等待 mutation job → 回读最终版本 → 取得默认与临时截图；能力隐藏与失败语义一致，不跨用户、不泄露存储键或票据（承接 G2-01）。
- 本地构建产物 ZIP 解压后以 `index.html` 为入口：全屏放映、双窗口（演讲者控制台 ＋ 观众唯一调度）、`timer` 与 `timeline_end` 推进、旁白与 cue 真实发声（承接 audio WP06/WP12 真机验收与 WP20 联调）。
- 长截图任务取消：attempt 终态、临时产物清理、Chromium 进程释放、槽位回 idle、迟到结果不提升产物（承接 G2-09）。
- 产出**实测缺口清单**：逐项区分能力缺失、配置/环境问题、文档与 AI 指引问题，标注严重程度与建议承接包（A2 / B0–B5 / C1–C3 / D1）。

## 不验证

指定状态截图（capture 常量长期为 False，B0 先替代默认海报采样、B1/B2 再删除取帧链）、混版与回退矩阵（G2-03 作废）、B01–B08 模型创作基准（G2-05 作废）。这三项即使在旧清单中是 P0/P1，也不在本包范围内。

## 验收

真实浏览器与真实 Renderer，不用开发服务器截图或单测替代。记录实际命令、版本、通过/失败数量、证据路径与未覆盖项。缺口清单逐项有承接结论。本包结束应能判定 motion G2 是否可关闭，以及 D1 是否有实测依据启动。
