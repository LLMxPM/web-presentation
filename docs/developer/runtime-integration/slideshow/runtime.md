# Runtime 翻页动画与自动放映实施计划

状态：M0 已实现（WP11、WP12：动画参数解析、过渡完成信号与真实 Chromium 验收）；调度、自动放映、媒体与双屏待实施。配置由 Backend 提供，字段和覆盖语义以[统一契约](./contract.md)为准。

实施拆分见[工作包执行清单](./work-packages/README.md)：WP11 动画与信号、WP13–WP16 调度及上下文、WP23–WP26 媒体与双屏、WP31–WP33 长期运行。以下 R 编号保留为上层职责。

## 1. 现有入口与拆分

- [PageTransitionHost.vue](../../../../runtime/src/runtime-shell/transitions/PageTransitionHost.vue)：双层动画、方向、快速导航合并及媒体离场暂停。
- [RuntimePageStage.vue](../../../../runtime/src/runtime-shell/transitions/RuntimePageStage.vue)：RouterView 接入，但尚未上送 `settled`。
- [runtime-session.ts](../../../../runtime/src/core/router/runtime-session.ts)：按 Router 隔离模式、导航意图和错误。
- [usePresenterController.ts](../../../../runtime/src/runtime-shell/presenter/usePresenterController.ts)：跨窗口导航和视图同步。
- [VideoViewer.vue](../../../../runtime/src/runtime-kit/internal/renderers/VideoViewer.vue)、[ViewPreview.vue](../../../../runtime/src/runtime-shell/preview/ViewPreview.vue)：视频与真实页面预览。

拟在 `runtime-shell` 下拆分放映控制器、就绪适配、媒体控制和窗口同步模块；不要向已经较大的 `ResponsiveLayout.vue`、`config.ts` 或 presenter 控制器持续堆入全部逻辑。

## 2. 工作包

### R01：参数解析与动画完成信号（M0，依赖 B03）

- [x] 消费 Backend 路由产物中的项目默认和叶子生效配置；保留旧产物缺字段时的手动行为和现有过渡兜底。
- [x] 将宿主 `settled` 和渲染错误向上接通，信号携带路径与本次页面 generation，避免旧页完成事件启动新页计时。
- [x] 动画以目标层的过渡完成事件为主要收尾条件，保留有界计时兜底；过滤子元素冒泡事件，无动画/减少动态效果也必须恰好完成一次。
- [x] 明确 `settled` 只表示整页过渡完成，不能替代页面 DOM/资源就绪；初次无动画挂载需在 DOM 提交后报告稳定页。
- [x] 当前页选择器排除离场层和缩略图，保留最多两层、反向推入、快速导航合并和失败恢复。

验收：默认与逐页动画在普通模式、观众窗口和构建产物一致；连续导航不重复完成、不残留旧媒体。

### R02：单窗口调度器（M1，依赖 R01）

- [ ] 将控制器绑定到 Router 会话而非页面组件，统一持有播放状态、当前路径、generation、剩余时间和计时句柄。
- [ ] 实现 `stopped`、`preparing`、`playing`、`paused`、`ended`、`blocked`、`error` 状态及明确的状态迁移；M1 不开放媒体模式。
- [ ] 等待“当前路由提交＋页面 DOM/必要视觉资源就绪＋过渡完成”后开始停留计时；资源失败保留可见错误并暂停，不无限等待。
- [ ] 复用现有导航目录和 `navigateRuntimePage`；只推进可见叶子页，隐藏页和分组不参与自动序列。
- [ ] 用单调时钟计算本窗口剩余时间，使用可取消的一次性调度，避免固定 interval 与导航耗时叠加。
- [ ] 手动跳页作废旧计时；播放中从新页重计时，暂停中保持暂停；停止保留当前页，重新开始从当前页计时。
- [ ] 手动模式页面等待用户操作；末页完成后按项目设置停止或循环，单页循环同样有完整停留周期。
- [ ] 普通窗口隐藏时暂停并保留剩余时间，重新可见后等待显式继续；回前台不连跳补课。自动开始只在本次宿主初始化时尝试一次。

验收：暂停/继续不丢剩余时间，过渡和加载不吃停留时间，任何旧回调都不能重复翻页。

### R03：执行上下文与操作区（M1，依赖 R02，向 G01 提供上下文契约）

- [ ] 引入内部执行上下文，区分放映主画布、单页交互预览、缩略图、捕获和导出；嵌入式普通单页预览优先采用禁自动策略。
- [ ] 缩略图、控制台当前/下一页小窗、卡片页、资源/组件预览禁止自动媒体播放；`inert` 只阻止交互，不能作为禁播实现。
- [ ] 捕获和导出强制禁用自动开始、翻页及媒体播放；执行上下文优先级高于项目和页面配置。
- [ ] 普通放映提供开始、暂停、继续、停止、剩余时间/页码与状态文字；保留现有导航快捷键，避免空格同时触发两个动作。
- [ ] 暂停放映同时暂停本会话媒体；只恢复此前正在播放的媒体，不启动用户手动暂停的媒体。
- [ ] 不把 Runtime shell 控制器、缩略图或 presenter 内部能力放入公开 Runtime Kit manifest。

验收：自动放映期间缩略图不抢播、捕获不跳页，卸载/模式切换清理计时和监听器。

### R04：媒体生命周期与结束翻页（M2，依赖 B06 的 Schema/权限适配及 R03）

- [ ] 当前活动画布内统一收集非循环原生音视频作为完成目标；`media_end` 主动播放并等待全部结束，没有目标时走停留时间。
- [ ] `VideoViewer` 转发播放、暂停、结束和错误状态，提供可控实例或内部注册；原生 HTML 媒体采用相同规则。媒体事件在实际元素上监听或显式转发，不能依赖 `ended` 冒泡。
- [ ] 目标页过渡前暂缓媒体启动，过渡完成后按模式执行；离场、取消、页面错误和卸载均停播并移除监听。
- [ ] 处理 `play()` Promise 拒绝，进入 `blocked` 提供点击开始；`error`、断网和 `media_timeout_ms` 到期进入错误暂停，提供重试、下一页、停止。
- [ ] 区分媒体停止、播放结束和循环；对多媒体、动态新增/移除、视频替换及迟到事件维护同页 generation 内的一次完成集合。
- [ ] 自动播放默认不能推断为成功；真实播放状态来自 Promise 和事件，兼容有声、静音与移动端行内播放。

本期受控范围是当前画布内的原生音视频及 `AssetVideo`。第三方 iframe 播放器、Web Audio、自定义脚本在画布外创建的音频和任意页面内部定时动画不纳入统一暂停/结束判定承诺；需要适配时单独增加版本化能力与验收，不能用 DOM 扫描宣称已覆盖。

验收：单/多视频、无视频、循环背景、播放被阻止和中途跳页均按[契约](./contract.md)执行。浏览器行为参见 [Chrome autoplay 说明](https://developer.chrome.com/blog/autoplay/)和 [MDN ended 事件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/ended_event)。

### R05：演讲者双窗口（M2，依赖 R04）

- [ ] 普通单窗口由当前窗口调度；双窗口由观众窗口唯一调度，控制台只发命令并显示状态，不运行第二个推进定时器。
- [ ] 扩展现有 BroadcastChannel/localStorage 兜底消息，携带协议版本、频道/产物身份、owner epoch、命令 ID、递增 revision、当前路径、状态和剩余毫秒。
- [ ] 新窗口 ready 后发送状态快照，重建本地时钟基准；不跨窗口直接比较 `performance.now()`，重复和过期消息必须去重。
- [ ] 进入/退出演讲模式先暂停，再交接状态；调度权交接必须先失效旧 owner。观众窗口未就绪或关闭时控制台保持暂停，重新打开需显式继续。
- [ ] 控制台隐藏不暂停仍可见的观众窗口；观众窗口隐藏/失去可执行条件时暂停。不能只依据控制台 `visibilitychange` 控制观众。
- [ ] 全屏退出本身不重置播放进度；现有演讲计时面板继续表示演讲用时，与放映剩余时间分开。
- [ ] 控制台手动跳页、观众键盘导航和恢复都经过统一控制器，避免消息回声与双重计时。

验收：控制台与观众状态一致、只有一次自动翻页，关闭重开和重复消息不会抢占或恢复旧播放。

### R06：长期无人值守（M3，独立增强）

- [ ] 评估固定发布产物入口、预览票据过期与资源访问失效，明确哪些场景支持续签、哪些需回工作台授权。
- [ ] 设计网络错误重试上限、显式恢复和故障提示，不因自动重试修改不可变快照。
- [ ] 在目标浏览器验证防休眠与退出清理，权限被拒时回退为普通放映；不默认申请或承诺所有设备可用。
- [ ] 完成多轮循环的媒体句柄、内存和监听器长稳验证；验收通过前不宣传全天无人值守。

## 3. 验证安排

纯控制器用虚拟时钟覆盖计时、暂停、作废回调、循环和状态迁移；挂载测试覆盖动画信号、上下文传播及媒体清理。真实浏览器验收动画、视频、权限、双窗口和缩放，不能仅依赖 JSDOM。具体场景、阶段门槛和证据见[验收计划](./acceptance.md)。
