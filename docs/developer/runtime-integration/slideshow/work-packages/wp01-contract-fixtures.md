- 修改范围：新增独立放映 DTO 和解析器；共享正反例覆盖项目完整值、路由整组覆盖、null/省略、严格整数及 snake_case/camelCase。

- 提交边界：只建立 Schema、解析和样例，不加数据库列、不开放 API 或自动播放能力。
