## 修改范围与交付

- 修改范围：固定构建产物（build artifact）浏览入口、私有资源鉴权、构建访问票据/按构建 Cookie 失效与续签边界、返回工作台/显式重新授权；补部署支持边界。入口对象不是创作预览 artifact，也不恢复 public fallback。
- 交付物：明确可长期使用的构建产物入口及到期可恢复路径，不改变不可变构建产物身份；公开发布仍是独立后续能力。
- 提交边界：入口与票据沿用[文件存储鉴权规划](../../file-storage-auth-cache-plan.md)的构建访问票据/按构建 Cookie 方案；如确需新增构建访问续签接口，另按接口/安全评审边界拆包，不在本包默认扩大授权。

## 完成标准

- [ ] 实现及评审覆盖上述修改范围，未超出提交边界。
- [ ] 行为验收：构建访问票据/Cookie 到期不混用预览票据、服务票据或用户票据，不恢复 public fallback；无法续签时明确退出或回工作台。
