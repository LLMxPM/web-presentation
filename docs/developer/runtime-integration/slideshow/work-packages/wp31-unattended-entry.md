## 修改范围与交付

- 修改范围：使用普通用户鉴权的现有下载入口取得真实、不可变的构建产物 ZIP，本地解压并按产物 `base_url` 启动静态文件服务进行放映；记录构建来源、入口文件、路由与资源可达性、浏览器参数和可重复步骤。远端构建访问入口、构建访问票据/按构建 Cookie、代理和续签不进入本包，交由后续独立代理服务另行设计、评审和验收。
- 交付物：可重复的本地构建产物放映步骤、支持边界，以及 WP32/WP33 使用的固定产物与启动方式。
- 提交边界：不新增或修改构建访问接口、票据、Cookie、代理、网关或部署入口；不恢复 public fallback；不以创作预览 artifact 或 Runtime 开发服务器替代真实构建产物；不把本地静态服务写成产品能力。

## 完成标准

- [ ] 实现及评审覆盖上述修改范围，未超出提交边界。
- [ ] 行为验收：产物来自真实构建任务且字节可校验；本地静态服务按产物 base 提供入口，路由、资源、字体和放映配置正常；重启本地服务和浏览器后可按步骤复现；匿名入口、票据和远端代理不参与验收。
- [ ] 验证范围：真实构建 → 鉴权下载 ZIP → 解压 → 本地静态服务 → 桌面浏览器放映一条链，核对 ZIP SHA-256 与构建记录。
- [ ] 关联验收：M3 专项：本地构建产物入口；见[联调与验收计划](../acceptance.md)。
- [ ] 记录代码版本、实际测试命令/结果、未运行项及原因，产物保存到任务专属临时目录。
- [ ] 回填本卡状态与证据；阶段能力是否开放由对应阶段出口包决定，单包完成不等于整阶段交付。
