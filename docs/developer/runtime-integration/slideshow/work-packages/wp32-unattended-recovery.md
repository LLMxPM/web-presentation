## 修改范围与交付

- 修改范围：本地构建产物放映下的屏幕防休眠（Screen Wake Lock）与权限拒绝回退、系统休眠/唤醒和前后台切换后的状态校验、本地静态服务中断及浏览器重载/崩溃后的显式恢复，以及退出后的 wake lock、媒体、计时器和监听器释放。
- 交付物：目标设备上的防休眠与恢复操作指引、可验证状态和清理证据。
- 提交边界：不默认申请设备权限，不承诺所有设备防休眠可用；不新增远端入口、票据或代理恢复逻辑，网络与构建访问票据故障由后续独立代理服务负责。

## 完成标准

- [ ] 实现及评审覆盖上述修改范围，未超出提交边界。
