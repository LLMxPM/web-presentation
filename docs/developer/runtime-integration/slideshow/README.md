# 翻页动画与自动放映实施总计划

状态：M0 已完成（WP01–WP12，2026-10-17）；M1 已完成（WP13–WP21，2026-10-17），已开放单窗口 timer 与手动翻页能力；M2 已完成（WP22–WP30，2026-10-18），已开放 schema 2、`media_end`、媒体超时和演讲者自动放映，捕获仍禁播；M3 已完成（WP31–WP33，2026-10-18），本地构建产物完成 61 分钟长稳与恢复演练，产品级远端无人值守仍依赖后续独立代理服务。

## 1. 目标与边界

实现由 Backend 管理项目默认值和逐页覆盖、Editor 配置、Runtime 执行的自动放映流程：开始放映 → 页面就绪 → 翻页动画结束 → 停留或播放媒体 → 下一页 → 结束或循环。

- Backend 是配置、默认值、校验和持久化的唯一权威；平台配置不读取 `runtime/public/config/`。
- 项目默认配置属于项目；逐页覆盖属于 `ProjectRoute`。同一页面资源被重复引用时，各路由可以有不同设置。
- 开始、暂停、剩余时长和当前媒体进度属于 Runtime 会话状态，不逐秒写入业务数据库。
- 放映参数单独维护；应用工作空间样式、另存为样式不会隐式覆盖项目放映设置。
- 首期复用 `none`、`fade`、`push`，保留旧项目的淡入淡出 400ms 和手动翻页行为。
- 本计划不包含逐元素动画编排、旁白生成、视频导出、PPTX 原生动画或远程设备控制。

## 2. 当前实现与缺口

| 模块 | 已有能力 | 主要缺口 |
| :--- | :--- | :--- |
| Backend | 项目配置、路由树、预览和构建快照、模板包 | 项目/路由模型与 DTO 无动画及放映字段，路由下发不携带这些参数 |
| Editor | 项目展示配置、可视化路由树、预览入口 | 无放映配置表单、继承说明和自动放映入口 |
| Runtime | 双层翻页宿主、无动画/淡入淡出/推入、全屏、手动导航 | 无统一调度器；`settled` 未接入上层；媒体和页面生命周期未联动 |
| 演讲者模式 | 当前页/下一页预览、备注、计时、跨窗口导航 | 计时按钮只控制计时；跨窗口不含播放状态和剩余时长 |
| Renderer/导出 | 捕获布局禁用翻页动画，Renderer 截图关闭 CSS 动画 | 缺少统一禁止自动翻页和媒体播放的执行上下文 |
| CLI/MCP | 依赖 External API 的项目配置和路由树能力 | 新字段需能力披露、完整往返和整树覆盖兼容 |

代码入口见各模块计划。此前定向 Runtime 测试为 11 个文件、38 项通过，只证明已有导航、过渡、演讲者与预览用例通过，不构成自动放映验收。

## 4. 阶段和依赖

| 阶段 | 必需工作包 | 阶段出口 |
| :--- | :--- | :--- |
| M0：配置与动画贯通 | B01–B05、E01–E02、R01、C01 | Backend 保存项目/路由配置，Editor 可设置，预览/构建动画一致，旧行为保留 |
| M1：单窗口定时放映 | E03、R02–R03、G01–G03、C02–C03 | 定时翻页、暂停续播、手动介入、末页循环可用，截图/导出稳定，客户端往返不丢配置 |
| M2：媒体与演讲者自动放映 | B06、E04、R04–R05、G04、C04 | 媒体结束翻页、播放受阻处理、双窗口唯一调度者和恢复通过验收 |
| M3：本地构建产物长稳验证 | R06 及运维专题 | 下载真实构建产物并在本地静态服务完成 60 分钟多页循环、防休眠与恢复专项；远端入口与票据由独立代理服务另行验收，不随 M3 开放 |

M0 先冻结 Backend 契约并产出共享样例，再推进 Editor 和 Runtime。M1 对外宣称单窗口定时自动放映；M2 完成前，演讲者模式继续保留手动放映，入口需明确可用范围。M3 不作为 M1/M2 的隐含承诺，只验证本地构建产物长稳，不代表产品级远端无人值守可用。

建议按可验收变更拆分：配置及迁移 → 动画下发和编辑 → 单窗口调度 → 捕获及导出隔离 → 外部客户端 → 媒体 → 双窗口。每次变更更新工作包状态和证据。

对应的具体阶段出口为 WP12（M0）、WP21（M1）、WP30（M2）、WP33（M3）；每包的完整前置、主责和验收项见[工作包执行清单](./work-packages/README.md)。首包从 WP01 配置 Schema 与共享样例开始。
