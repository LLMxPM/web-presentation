## 1. 验证层次与数据

- Backend 单测/API 测试验证配置合法性、事务、权限、迁移、幂等和模板往返；共享样例约束 API 与 Runtime 数据转换。
- Editor 测试验证草稿、继承/null、生成类型、提交与错误反馈；Runtime 虚拟时钟验证调度和旧回调失效。
- 真实浏览器验证 CSS 过渡、媒体、全屏、双窗口和可见性；远程截图必须检查实际 PNG，导出必须检查实际文件。
- 准备独立 fixture：可见封面、分组子页、隐藏页、同一页面重复引用、末页；另有无视频、单视频、多视频、循环背景、失效资源和延迟加载页。
- 验证使用不可变 artifact/snapshot，记录项目默认与路由原始覆盖；E2E 使用技能规定的隔离库和 mock 环境，不重置开发数据。

| A17 | CLI/MCP 读改写和旧服务兼容 | 显式覆盖/null 不丢失；只读字段不回写；旧服务明确不支持 |

WP13 的虚拟时钟用例已覆盖 A09、A11、A12、A13 的纯调度层（就绪前后计时、暂停剩余时间、旧回调失效、末页/循环/单页循环）；WP14 的宿主与媒体守卫用例已覆盖 A14–A16 的执行上下文优先级、缩略图/预览禁自动播放和暂停媒体记录；WP15 的宿主集成用例覆盖 A09/A10/A12/A13 的 Router 绑定、延迟就绪、旧 settled、导航错误和捕获禁推进。WP16 已在真实 Chromium 中验证 A09/A11/A14/A15：1200ms/3000ms 不可变快照自动计时、暂停/继续、后台隐藏不补跳、全屏空格不双触发、卡片模式清理、停止保留当前页，以及 Editor 三档宽度入口。 WP21 在 Chromium 中补充 A10/A12/A13：600ms 过渡 + 1200ms 停留的过渡后计时（1806ms/1866ms）、播放与暂停中手动跳页/连跳、`history.back` 后旧计时失效、末页循环（1756/1831/1867ms）、单页循环和隐藏页跳过，21 项检查全部通过。WP17 验证 A15 的远程截图真实 PNG；WP18 验证 A16：暂停状态下 PDF/PPTX/打印顺序与内容正确，导出取消不下载且不改变主画布页码、剩余时间与路由。A12 的真实手动连跳仍以 WP21 为准。

虚拟时钟对业务剩余毫秒进行确定性断言。真实浏览器测试记录导航提交、过渡结束和下一次导航时间，运行前声明前台计时容差及设备环境，不能用宽泛 sleep 代替行为判定。

## 4. M2：媒体与双窗口

| 编号 | 场景 | 通过条件 |
| :--- | :--- | :--- |
| A18 | 单/多非循环媒体、无媒体、循环背景 | 等待全部目标结束；无目标走停留时间；循环背景不阻塞 |
| A19 | 静音、有声、播放受阻、错误和超时 | 状态基于真实播放结果；受阻/错误有重试、下一页和停止入口 |
| A20 | 媒体播放中暂停、跳页、替换或卸载 | 恢复原进度和正确媒体；旧页事件不能推进新页；无残留声音 |
| A21 | 控制台导航、观众键盘和自动翻页 | 双方状态一致且只有观众窗口调度，不重复推进 |
| A22 | 窗口先后加载、关闭重开、重复/旧消息 | 新快照能恢复，旧 owner 失效；断开后暂停并显式继续 |
| A23 | 控制台隐藏、观众隐藏和退出全屏 | 按实际观众可见性处理；全屏变化不重置剩余时间 |
| A24 | 媒体模式下远程截图与取消/期限 | 捕获禁播、PNG 正确、槽位和浏览器进程/临时产物释放 |

桌面 Chromium 必测；Firefox/WebKit 的媒体与全屏差异记录为支持矩阵，未验证浏览器不列为已支持。跨域 iframe 授权使用真实预览拓扑，不能只在同源测试页上验收。

WP26 在独立 Runtime（7373，同源 standalone，4s timer）用两个真实 Chromium 窗口验证 A21–A23：控制台先加载时保持未连接且不接管推进，观众后加载后显式开始；自动翻页间隔 3947ms/8016ms、控制台跟随且无双重计时；控制台/观众键盘与页面按钮导航一致。控制台隐藏时观众继续自动翻页；观众隐藏后暂停、4.5s 内不翻页，重新可见保持暂停且剩余时间未重置，显式继续后完成翻页。全屏进入/退出剩余时间 0:04→0:03→0:03→0:02。关闭观众窗口后回显“已关闭”并暂停，重开未显式开始 4.5s 内不翻页；重复、旧 owner 与旧 revision 注入不改变路径。Firefox/WebKit 与媒体模式双窗口仍由 WP30 回归。

## 5. 兼容与发布

| 组合 | 预期 |
| :--- | :--- |
| 新 Runtime + 旧 artifact/旧配置 | 兼容为手动翻页，保留旧默认动画，不误启动 |
| 新 Backend + 旧客户端 | 可读取新增字段；匹配节点整树更新保留覆盖；新模式需能力检测 |
| 新客户端 + 旧 Backend | 新参数返回明确不支持或校验失败，不能伪装保存成功 |
| 新 Backend 配置 + 旧 Runtime 执行池 | 不验收为支持；发布前升级配套 Runtime 或阻止开放新能力 |
| 新模板导入器 + schema 1/2/3 | 三版本均接受，旧包补默认；schema 3 保留原始覆盖 |
| 旧模板导入器 + schema 3 | 明确拒绝，不静默丢失放映字段 |

配置快照、Runtime 构建身份和能力版本一起记录；已有历史 artifact 不重写。发布前完成迁移备份、同版部署验证和回滚说明，旧应用回滚不等于新模板/新配置可被旧版本完整编辑。
