# 自动放映联调与验收计划

状态：M0 已验收（2026-10-17）；M1 进行中，WP13–WP16 的调度、执行上下文、Router/就绪桥接与单窗口入口/控制条已完成（2026-10-17），导出隔离待实施。A01–A08 的真实预览/构建、双库迁移、模板与 Chromium 动画证据见 [WP12 实施记录](./work-packages/wp12-m0-integration.md)；A09/A11/A14/A15 的 M1 真实浏览器证据见 [WP16 实施记录](./work-packages/wp16-playback-entry-controls.md)；其余场景仍为待执行验证计划，不代表已运行功能验收。字段以[统一契约](./contract.md)为准，工作包以[总计划](./README.md)为准。

执行分工见[工作包清单](./work-packages/README.md)。阶段出口分别为 [WP12](./work-packages/wp12-m0-integration.md)、[WP21](./work-packages/wp21-m1-integration-release.md)、[WP30](./work-packages/wp30-m2-integration-release.md)、[WP33](./work-packages/wp33-unattended-soak-release.md)，负责汇总本阶段场景与真实产物证据。

## 1. 验证层次与数据

- Backend 单测/API 测试验证配置合法性、事务、权限、迁移、幂等和模板往返；共享样例约束 API 与 Runtime 数据转换。
- Editor 测试验证草稿、继承/null、生成类型、提交与错误反馈；Runtime 虚拟时钟验证调度和旧回调失效。
- 真实浏览器验证 CSS 过渡、媒体、全屏、双窗口和可见性；远程截图必须检查实际 PNG，导出必须检查实际文件。
- 准备独立 fixture：可见封面、分组子页、隐藏页、同一页面重复引用、末页；另有无视频、单视频、多视频、循环背景、失效资源和延迟加载页。
- 验证使用不可变 artifact/snapshot，记录项目默认与路由原始覆盖；E2E 使用技能规定的隔离库和 mock 环境，不重置开发数据。

| 编号 | 场景 | 通过条件 |
| :--- | :--- | :--- |
| A01 | 旧库升级、新建项目、旧模板导入 | 默认淡入淡出 400ms、手动翻页；没有意外自动开始 |
| A02 | 项目默认与两组路由覆盖 | 查询值、原始覆盖、生效值、Runtime 下发符合统一契约 |
| A03 | null、字段省略、分组非法覆盖与越界参数 | 省略/清除语义正确，非法写入整体失败且旧树不变 |
| A04 | 旧客户端整树保存、路由移动/重命名、重复引用 | 匹配的旧节点保留覆盖；新版客户端移动后不丢设置；重复引用互不影响 |
| A05 | API、External、权限和幂等 | 同输入同结果；无权读取/写入失败；省略与 null 使用不同语义指纹 |
| A06 | 预览、历史、下载构建、模板 1/2/3 | 当前快照一致；历史不变；三版本模板可导入，新包往返等价 |
| A07 | none/fade/push、反向翻页和快速导航 | 效果及方向正确，最多两层，结束无残留；减少动态效果立即稳定 |
| A08 | 应用样式、另存为样式、复制页面 | 放映参数归属正确，不被样式应用或页面资源复制隐式改变 |

## 3. M1：单窗口定时自动放映

| 编号 | 场景 | 通过条件 |
| :--- | :--- | :--- |
| A09 | 从首页/当前页开始，进入后自动开始 | 起点正确，初始化只启动一次，手动模式页面等待操作 |
| A10 | 延迟挂载、资源就绪、动画耗时 | 停留计时从就绪且过渡结束后开始；失败可见且不无限等待 |
| A11 | 暂停、继续、停止和重复点击 | 剩余时间保持；停止保留当前页；只有一个调度句柄 |
| A12 | 播放中/暂停中手动跳页、连跳及浏览器导航 | 旧回调失效，新页按当前播放状态处理，不重复翻页 |
| A13 | 末页结束/循环、单页循环、隐藏页 | 自动边界符合配置；手动边界不绕回；每轮有完整停留周期 |
| A14 | 后台隐藏、切回、切换卡片/演讲模式 | 状态按 Runtime 计划暂停，切回不连跳，旧模式计时清理 |
| A15 | 缩略图、控制台小窗、单页/组件/资源预览 | 自动开始不生效，预览不抢播，不创建后台推进器 |
| A16 | 自动放映配置下截图、PDF/PPTX/打印 | 真实产物路由、顺序、尺寸正确，无离场层；取消不污染主放映 |
| A17 | CLI/MCP 读改写和旧服务兼容 | 显式覆盖/null 不丢失；只读字段不回写；旧服务明确不支持 |

WP13 的虚拟时钟用例已覆盖 A09、A11、A12、A13 的纯调度层（就绪前后计时、暂停剩余时间、旧回调失效、末页/循环/单页循环）；WP14 的宿主与媒体守卫用例已覆盖 A14–A16 的执行上下文优先级、缩略图/预览禁自动播放和暂停媒体记录；WP15 的宿主集成用例覆盖 A09/A10/A12/A13 的 Router 绑定、延迟就绪、旧 settled、导航错误和捕获禁推进。WP16 已在真实 Chromium 中验证 A09/A11/A14/A15：1200ms/3000ms 不可变快照自动计时、暂停/继续、后台隐藏不补跳、全屏空格不双触发、卡片模式清理、停止保留当前页，以及 Editor 三档宽度入口。A12 的真实手动连跳、Renderer/导出产物证据仍以 WP17/WP18/WP21 为准。

虚拟时钟对业务剩余毫秒进行确定性断言。真实浏览器测试记录导航提交、过渡结束和下一次导航时间，运行前声明前台计时容差及设备环境，不能用宽泛 sleep 代替行为判定。

## 4. M2：媒体与双窗口

| 编号 | 场景 | 通过条件 |
| :--- | :--- | :--- |
| A18 | 单/多非循环媒体、无媒体、循环背景 | 等待全部目标结束；无目标走停留时间；循环背景不阻塞 |
| A19 | 静音、有声、播放受阻、错误和超时 | 状态基于真实播放结果；受阻/错误有重试、下一页和停止入口 |
| A20 | 媒体播放中暂停、跳页、替换或卸载 | 恢复原进度和正确媒体；旧页事件不能推进新页；无残留声音 |
| A21 | 控制台导航、观众键盘和自动翻页 | 双方状态一致且只有观众窗口调度，不重复推进 |
| A22 | 窗口先后加载、关闭重开、重复/旧消息 | 新快照能恢复，旧 owner 失效；断开后暂停并显式继续 |
| A23 | 控制台隐藏、观众隐藏和退出全屏 | 按实际观众可见性处理；全屏变化不重置剩余时间 |
| A24 | 媒体模式下远程截图与取消/期限 | 捕获禁播、PNG 正确、槽位和浏览器进程/临时产物释放 |

桌面 Chromium 必测；Firefox/WebKit 的媒体与全屏差异记录为支持矩阵，未验证浏览器不列为已支持。跨域 iframe 授权使用真实预览拓扑，不能只在同源测试页上验收。

## 5. 兼容与发布

| 组合 | 预期 |
| :--- | :--- |
| 新 Runtime + 旧 artifact/旧配置 | 兼容为手动翻页，保留旧默认动画，不误启动 |
| 新 Backend + 旧客户端 | 可读取新增字段；匹配节点整树更新保留覆盖；新模式需能力检测 |
| 新客户端 + 旧 Backend | 新参数返回明确不支持或校验失败，不能伪装保存成功 |
| 新 Backend 配置 + 旧 Runtime 执行池 | 不验收为支持；发布前升级配套 Runtime 或阻止开放新能力 |
| 新模板导入器 + schema 1/2/3 | 三版本均接受，旧包补默认；schema 3 保留原始覆盖 |
| 旧模板导入器 + schema 3 | 明确拒绝，不静默丢失放映字段 |

配置快照、Runtime 构建身份和能力版本一起记录；已有历史 artifact 不重写。发布前完成迁移备份、同版部署验证和回滚说明，旧应用回滚不等于新模板/新配置可被旧版本完整编辑。
