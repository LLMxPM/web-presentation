## G2 发布与模型创作基准

当前执行状态、遗留项与关闭条件见 [G2 遗留清单](./g2-followups.md)；本节保留验收口径。G2 要求 G1 全部关闭，并完成以下联合场景：

- Editor 页面预览显式播放、暂停、重播、定位、偏好模拟和默认 poster；响应式控件遵守根 DESIGN。
- 同一示例通过内置助手与 CLI 读取能力、创建、修改、等待 mutation job、查询最终版本并获取默认/临时截图。MCP 暂不提供服务，不列入本轮 G2。
- 真实 Backend 桥接页与独立 Runtime 源站，受保护视频/audio 的 HEAD、Range 与跳转定位；不依赖 public fallback。
- 生产依赖裁剪后的镜像可启动，独立构建脱离开发服务器播放并可静态导出；新 Runtime Kit 的依赖闭包与资源完整。
- 新旧放映配置、v1/v2 渲染协议、旧 v1 Asset 组件与新 v2 内容的混版行为符合运行契约；不支持时明确失败。
- 至少 30 分钟受控循环，记录漂移、卡顿、JS 堆、媒体元素、RAF/计时器、WebGL 资源和浏览器进程；不把本地验收扩展成无人值守全天承诺。

### 八个模型任务

G0 原型及独立 Luna 小样用于检查创作表达性和反馈恢复，任务/样本方法单独保存，不与本表正式 G2 基准混计。G2 固定模型与版本、工具集合、系统规范、种子资源和每任务修正轮数，记录 token/耗时，不借机发送用户业务消息或修改开发数据。

| 编号 | 任务 |
| :--- | :--- |
| B01 | 标题与三张图片错峰进入，静态海报可读 |
| B02 | 旁白作为主媒体，同步两段说明文字 |
| B03 | 从真实查询动作中选择模型片段，和标题同时开始 |
| B04 | 模型动作结束 200ms 后播放裁切且静音的视频 |
| B05 | 将 B04 的模型动作延后 500ms，后继自动顺延 |
| B06 | 同一模型两个实例分别停在不同时间并截图 |
| B07 | 根据轨道属性冲突与过期动作引用错误修复 |
| B08 | 区分 reduce、blocked、buffering 与静态截图，给出与证据一致的解释 |

候选发布目标：至少 7/8 首轮编译与业务校验通过，8/8 在最多一轮有界错误反馈后通过；B05 不修改无关轨道，B08 不编造已检测状态。记录失败样例与 API 修改原因；若达不到，先简化接口或错误反馈，不以增加长提示掩盖接口问题。

### 支持矩阵与证据

桌面 Chromium 是首期发布基线。Firefox/WebKit、移动端、直播、第三方 iframe、跨页 BGM 和离线视频导出未验证时明确不列入支持范围。媒体容差基于实际解码帧率，不承诺任意设备严格帧同步。

证据至少包含代码版本、Schema/引擎版本、设备/浏览器、命令、样例 hash、轨道计划摘要、时序记录、可读产物和未运行项。Renderer 还记录同 attempt 的状态回执、PNG、取消清理和槽位释放。文档中的测试通过只描述实际跑过的命令。
