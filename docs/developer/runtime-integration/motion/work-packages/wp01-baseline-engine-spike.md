# WP01 基线与执行器验证

状态：**完成（2026-10-21），G0 功能选型通过。** 主责：Runtime / 技术验证。前置：无。出口：G0。最终依据为[G0 决定](../g0-decision.md)，前序候选与失败证据保留，不把首轮 WAAPI 判断或历史性能数字当成当前决定。

## 输入与落点

阅读 [总规划](../README.md)、[创作契约](../authoring-contract.md) 和 [验收目标](../acceptance.md)。复核当前 execution-policy、PageMediaSession、ModelViewer、OffscreenPageStage 与预览版本身份，不以旧规划中的“待实施”代替代码现状。

## 交付

- 先比较 GSAP、Anime.js、Motion 和 WAAPI 的原生段落、并行、标签、错峰、复用、对象与定位，再比较 AI 在 Vue SFC 内的完整生成、局部修改及错误恢复。最终再选默认创作入口与引擎。
- 记录依赖体积、生产依赖裁剪后的加载方式、离线构建、取消清理、样式固化与跨域预览限制；评估所选依赖的当前使用条件。
- 准备短旁白、带时间可辨画面的视频、包含动作的自包含 GLB，以及无动作/缺失目标/重复动作等反例；保存来源、文件 hash 和生成说明。
- 当前阶段不比较性能；首轮规模与性能数据只作历史证据。默认创作方式确定后再复核预算，不能据旧数值锁定执行器。
- 完成六至八个创作草案的小样比较，确认定义可以局部修改，产出 G0 选择记录并修正契约。

## 不包含

不发布 Runtime Kit 项、不修改用户系统动画设置、不安装两套生产执行器、不把一次同源示例作为跨域产品验收。

## 验证与通过条件

覆盖 A03、A04、A06、A09、A13 的最小真实浏览器原型，记录直接采样与乱序 seek 后采样的一致性。候选预算不能通过主观“看着同步”关闭。

G0 记录必须明确引擎、默认创作形状、不能满足的情况与剩余改动；本轮按用户要求不比较或冻结性能/规模预算。出口为固定模板八任务至少7/8首次、8/8在一次反馈内通过，以及裁剪依赖/独立构建功能可行，不能以此替代后续产品验收。
