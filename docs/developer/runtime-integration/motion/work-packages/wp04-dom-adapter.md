# WP04 DOM 动效适配器

状态：待实施。主责：Runtime。前置：[WP03](./wp03-transport-targets.md)。

## 输入与落点

消费 WP02 的轨道与适配接口，以及 WP01 选定的单一 DOM 执行器。新增 core/motion DOM 适配器，图标、图片和 SVG 容器继续使用现有资产能力。

## 交付

- 实现 fade/fade-up、明确 from/to 的透明度、二维变换和文本标记；按标签或 afterTrack 执行相同计划。
- 将布局与动画变换分层，保留外层居中、旋转与定位；同属性重叠由编译器拒绝，不靠 CSS 层叠偶然取胜。
- 首次挂载不提前自动播放；按宿主许可从 poster 或逻辑 0 应用状态。
- 实现 system/reduced/full 的视觉映射；基础样式可读，闪光或遮罩不因统一 opacity=1 遮挡正文。
- 实现 sample/freeze 与样式恢复，保证 animations=disabled、离屏舞台和几何测量不改变已选状态。
- 所选执行器的 context、动画对象与内联属性在取消/卸载时恢复或释放，不修改全局 timeline。

## 验证与通过条件

覆盖 A03、A12、A13 的 DOM 部分；真实 Chromium 比较 t=0、中间帧与结束帧，以及乱序 seek、reduced 与完整效果。检查 freeze 后再截图不会跳到结束帧。

类型检查与生产构建包含真实执行器依赖；不能只在 jsdom 中断言样式字符串。

## 不包含

任意 CSS、文字逐字拆分、SVG morph、图表内部动画及未注册页面动画的自动接管。
