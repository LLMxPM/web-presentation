## 修改原则

- 新增能力时优先复用已有 UI 组件和交互模式。
- API 请求层不要散落在视图组件里。
- 账户 AI 设置页要展示完整工具说明和只读契约信息。
- 账户 AI 设置页使用“聊天模型 / 图片生成 / 内容助手”三个区域。Chat 与图片配置调用独立接口和表，列表、筛选和新增/修改表单不得重新合并 `model_type` 分支；聊天供应商与模型从本地 Models.dev 缓存选择，也允许自定义 OpenAI-compatible 连接，图片供应商只来自 Backend 图片注册表。目录能力默认只读，只有高级配置中的显式 `capability_override` 才能覆盖。
- 预览 iframe 只呈现 Runtime 结果，不承载 Runtime 内部逻辑。
