## 修改原则

- 新增能力时优先复用已有 UI 组件和交互模式。
- API 请求层不要散落在视图组件里。
- 账户 AI 设置页要展示完整工具说明和只读契约信息。
- 账户 AI 设置页按 `provider_type` 区分 Chat 与图片生成供应商；两类供应商独立创建，模型表单只展示与 `model_type` 兼容的供应商配置，切换模型类型时清空或替换不兼容选择。
- 预览 iframe 只呈现 Runtime 结果，不承载 Runtime 内部逻辑。
