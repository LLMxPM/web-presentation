## 使用与维护

1. 下一轮工作从现行执行计划开始，按前置条件选择批次，不重新执行历史排期。
2. 计划只维护当前状态、下一动作和证据链接；详细命令、失败、复测与产物进入运行目录。
3. 复用历史结果必须核对候选与覆盖输入；新增修改只重开受影响场景和必要跨域回归。执行拓扑变化（如 Lite 由两容器改为单镜像）后，旧拓扑的结果不得直接背书新形态。
4. 部署形态收敛、Lite 单镜像与环境变量治理属于本轮；全仓按行数重构、微服务拆库和新增产品能力按后续需求单独论证。
5. 未验收范围保持开放；类型检查、健康接口、镜像构建和归档均不代替业务验收。
6. 永久模块契约继续维护在 [developer/architecture](../developer/architecture/README.md) 与 [developer/deployment](../developer/deployment/README.md)，本目录不替代 AGENTS.md、接口规范或正式部署文档。
