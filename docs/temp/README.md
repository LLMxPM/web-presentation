## 使用与维护

1. 下一轮工作从现行收尾计划开始，按前置条件选择批次，不重新执行历史排期。
2. 计划只维护当前状态、下一动作和证据链接；详细命令、失败、复测与产物进入运行目录。
3. 复用历史结果必须核对候选与覆盖输入；新增修改只重开受影响场景和必要跨域回归。
4. 核心正确性、权限、数据和恢复问题属于本轮；全仓重构、Lite 合并与新增产品能力按后续需求处理。
5. 未验收范围保持开放；类型检查、健康接口、镜像构建和归档均不代替业务验收。
6. 永久模块契约继续维护在 [developer/architecture](../developer/architecture/README.md)，本目录不替代 AGENTS.md、接口规范或正式部署文档。
