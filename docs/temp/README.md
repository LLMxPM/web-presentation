- 新一轮评估带日期；旧评估和计划归档并加横幅，保留历史正文，仅修复迁移链接。
- 每个结论区分静态确认、静态缺口、待验收和历史证据；不把远端配置或旧镜像数字当当前事实。

- 新的专项如需独立成文，应隶属现行工作包，不再创建第二套总计划。

- 产品已接受项只登记，只有明确的目标变化或复审触发条件成立时重开。
- 归档后同步更新链接与导航；正式文档引用旧方案时标明历史来源。
