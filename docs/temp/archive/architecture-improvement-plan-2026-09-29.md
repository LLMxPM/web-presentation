### 2.1 W02 的约束

- OpenAPI 导出应在隔离配置下可重复，不依赖开发者正在运行的服务；不能静默连业务数据库或下载生产数据。
- 手写兼容层可以短期保留，但必须有明确映射和迁移边界；不能长期依赖 8 类字段名子集测试代表完整类型契约。
- JSON Schema 结构验证与 Runtime Kit/工作空间引用授权是两层检查，接入前者不能删除后者。
- 保留四类防漂移反例：Backend 字段类型、可选改必填、非法 previewSchema 嵌套字段、删除指定 method/path 但保留相同前缀。只有新契约输入或失败暴露未覆盖情况时才扩展。
- 不修改 External API v1 的 `canceled` 拼写来追求内部统一；破坏性变化需单独迁移方案和消费者验证。

### 2.2 W03 的约束

- 使用真实队列状态词汇，避免另一份不受约束的映射；缺列不能无声地等同“没有过期租约”。
- 给 pending、运行占用、供应商等待、Batch 续跑分别定义时间起点与单位。
- 页改/图片领域 Job 与 ExternalTask 的关系要可解释；组件执行虽存于 ExternalTask，也必须能单独观察。
- 用非空 fixture 验证正常排队、重试等待、执行、过期租约和终态；空库只作为补充。
- 采集开销也计入 M03。快照中的最老年龄不能直接冒充所有请求的 P95，分位数需从带时间戳的任务样本计算。

剩余实现与采样要求：

1. 为可关联的逻辑请求与执行 attempt 保留入队、开始、结束时间及结果；分别计算 `queue_wait_ms`、`execution_ms` 和端到端时间，重试等待与多 attempt 单独说明。输出到达/完成/失败/拒绝/超时/取消/在途数量，阶段结束继续采集至排空。
2. 指标只保存必要标识、时间与错误码，不复制页面源码、模型历史或密钥。汇总的单位延续 v2 分层；领域 Job、ExternalTask 与 Attempt 不重复算成用户请求。
3. M03-F1 记录被拒绝的操作、实际 UTF-8 大小、单项/总量预算、现有占用和清扫结果。先复现拒绝位置，再确定是 payload 设计、预算记账、错误映射还是测试构造的问题，不能直接提高上限。
4. 修正 drill：small/medium/large 应构造可区分的 artifact 负载；另设同项目重复新建预览以验证 TTL/清扫，不把这三次同项目预览称为三档模块测试。预算内、单项超限、总量超限分别留证，失败也必须输出结果。
5. M03 的预览、页更、截图、构建使用独立请求生成器，记录实际到达率与阶段边界；图片、资源导入/归档另标可用依赖与样本，未采集的类型不得并入容量结论。

### 2.4 W05b 普通 Run 的 owner 存活与收敛

- 在平台持久化层登记具体进程实例身份与心跳，失效判定与模型事件空闲时间分开。hostname/PID/实例身份重建与重用都应可辨别，普通 Run 启动与继续执行时绑定实际执行 owner。
- 用独立后台收敛路径处理 owner 失效遗留；终态提交在同事务以 owner、Run 状态与取消状态复核 CAS，保护其它副本、同机 sibling 和仍有效的执行。所有 Run 相关写入遵守既有写围栏。
- paused、waiting_external 与持有有效 Batch 续跑租约的 Run 不得按普通进程遗留处理；收敛条件需与外部协调器交接语义联动验证。历史缺 owner/无心跳记录采用显式迁移/宽限规则，不能恢复全局扫杀。
- 收敛为失败或取消后，会话可再次启动；SSE、查询接口继续只观察，普通 Run 不自动恢复模型执行。用户 `force_cancel` 保留为手动补偿。
- 开跑前固定 owner TTL、心跳与扫描周期，以及租约/写冲突重试的预算；记录由这些参数推导的终态上界，实测不得只比较一次结果与租约秒数。

### 2.5 W05c 预览版本绑定与传播

- 镜像/发布配置注入确定的构建标识，同一发布的副本使用相同值；副本 ID 独立记录。`dev` 仅代表开发形态，不能作为生产镜像同版证明。
- 服务端创建预览时绑定期望版本，选择可覆盖浏览器导航与相关子请求的机制；可采用受控版本路径/路由或签名上下文传播。无需浏览器用户手工增加请求头，也不依赖本进程临时 token 缓存保证正确性。
- HTML、页面/组件模块、CSS、Vite/HMR 等相关请求应维持同一版本语义；Backend/Gateway 代理保留诊断所需的版本与错误信息。版本不支持时明确拒绝，不把失配映射成源码错误或 500。
- 同版副本间强制分发仍应可用；跨版必须稳定路由或明确拒绝。验收前保持同版池与排空切换，不因入口 409 放开混版。
- manifest/令牌/HTTP DTO/Runtime Kit 或 Renderer 协议有变更时，联动相应契约包、生成物、指纹缓存输入与消费者测试；接口与公开 import path 继续遵循版本化规则。
