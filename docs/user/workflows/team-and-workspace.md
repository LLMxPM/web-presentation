# 用户与工作空间管理

`web-presentation` 支持多用户管理与多工作空间隔离，非常适合个人创作者以及小型团队在私有化部署环境下使用。平台目前已实现多用户账号隔离与用户自建工作空间；**同一个工作空间内的多成员协作与共享属于待实现的功能**。

---

## 1. 初始安全基线

首次通过 Docker、NAS 或服务器完成私有化部署后，系统会使用预设的管理员密码（由环境变量 `DEFAULT_ADMIN_PASSWORD` 指定，默认可能为 `change-admin-password` 或模板配置密码）。

为了保障服务安全，部署完成后请立即完成密码更新：

1. 打开平台访问地址，使用管理员账号登录（默认用户名通常为 `admin` 或对应预设账号）。
2. 点击右上角用户头像，进入“用户菜单”或通过侧边栏导航进入管理后台。
3. 修改当前管理员密码为强密码并妥善保存。

---

## 2. 平台用户管理

仅拥有平台管理员（`platform_admin`）角色的账号可以访问用户管理面板。

### 2.1 访问路径

点击顶部导航栏右上角的个人头像，在下拉菜单中选择 **“用户管理”**（或直接访问 `/admin/users`）。

### 2.2 创建团队成员账号

1. 在用户管理页面，点击右上角的 **“添加用户”** 按钮。
2. 填写新成员信息：
   - **用户名**：团队成员登录所用的唯一标识（建议使用英文、数字或拼音，如 `zhangsan`）。
   - **姓名/昵称**：界面展示用名称（如“张三”）。
   - **初始密码**：为该成员指定的初始登录密码。
   - **平台角色**：普通成员选择 `member`（常规创作人员）；若需共同维护平台与所有工作空间，可赋予 `platform_admin`。
3. 点击“确定”完成创建，将账号与初始密码告知团队成员。成员登录后可在个人中心自行修改密码。

### 2.3 账号状态维护与重置密码

- **重置密码**：若成员遗忘密码，平台管理员可在用户列表中找到对应行，点击“重置密码”并输入新密码。
- **禁用账号**：当团队成员离职或不再参与项目时，管理员可将其状态切换为“禁用”，禁用后该账号将无法再登录系统，但其历史创建的项目和资产仍会完整保留在对应工作空间内。

## 3. 工作空间管理

**工作空间（Workspace）** 是平台组织创作项目、资源库、组件库与设计系统的核心单元。

### 3.1 核心概念与权限边界

平台目前提供清晰的角色与权限隔离：

| 角色 | 权限范围 | 说明 |
| :--- | :--- | :--- |
| **平台管理员 (Platform Admin)** | 全局最高权限 | 可管理所有用户、切换并进入所有工作空间、维护系统设置 |
| **工作空间所有者 (Workspace Owner)** | 空间级完全控制 | 工作空间的创建者，可修改工作空间名称/描述、删除空工作空间、管理空间内所有项目与资产 |
| **同空间成员共享 (待实现)** | 空间内多用户协作 | *规划建设中*。支持将特定工作空间授权共享给其他注册用户共同编辑 |

> [!IMPORTANT]
> **功能边界提示**：平台目前已实现多用户账号隔离以及各用户自建工作空间；**同一个工作空间内的多用户成员共享与邀请协作属于待实现的功能**。在当前版本中，每个用户创建的工作空间仅限创建者本人（以及全局平台管理员）进入与创作。

### 3.2 创建与切换工作空间

1. 点击左上角的工作空间切换器（当前工作空间名称旁的小箭头）。
2. 在下拉面板底部点击 **“新建工作空间”**。
3. 输入工作空间名称（如“市场营销”、“技术方案”、“个人创作”）和空间描述，点击确认。
4. 创建成功后，系统会自动将当前用户设为该工作空间的所有者，并自动切换到新空间。
5. 随时可通过左上角切换器在个人的多个工作空间之间无缝切换。

### 3.3 工作空间共享与成员协作（待实现）

同一个工作空间内的多成员协同是后续版本规划中的重点能力：

- **现状说明**：当前前端界面暂未开放工作空间成员管理与邀请入口，各注册用户的创作工作空间完全相互独立。
- **当前的团队资产流通方式**：若团队成员之间需要复用已做好的演示母版或组件，推荐使用**模板离线包**进行流通：
  - **项目级分享**：在项目操作栏点击 **“导出”** 生成离线包（`.zip`），同事在其工作空间中点击“导入项目”即可完整复现；
  - **组件级分享**：在组件工作台使用 **“导出分享包”**，同事可将其直接导入至自己的工作空间组件库中。
- **未来规划**：待工作空间共享能力上线后，空间所有者可直接通过成员列表邀请同事加入，实现真正的同空间跨用户资产实时共享与多人协作。

## 4. 资产共享与隔离机制

理解工作空间的边界，能帮助创作者更加高效地组织资产：

```
[ 工作空间 A：市场营销 ]
   ├── 空间内公共资源库（企业 Logo、VI 色卡、官方宣传图）
   ├── 空间内组件库（官方封面、产品亮点卡、数据图表）
   ├── 空间内主题与字体（品牌专属主题、思源黑体）
   └── 项目群（2026新品发布会、Q3营销策划...）

[ 工作空间 B：技术方案 ]
   ├── 空间内技术资源库（架构拓扑图标、流程图、Mermaid 配置）
   ├── 空间内组件库（代码展示卡、接口监控看板、技术路线图）
   └── 项目群（微服务架构演进、运维年度复盘...）
```

- **空间内资产聚合复用**：在同一个工作空间内，所有项目均可自由选用该空间的公共素材、直接调用已发布的共享组件，并应用统一的主题与样式规范。
- **跨空间严格数据隔离**：不同工作空间之间的项目、草稿、资源和组件互不可见、互不干扰。
- **跨用户协作边界**：因同一个工作空间的多成员共享功能属于待实现功能，当前各用户的工作空间处于相互独立的隔离状态。团队协作目前通过离线模板包的方式在各用户工作空间之间流通。

---

## 5. 最佳实践建议

### 5.1 个人多空间分类
- **善用“工作空间”做场景隔离**：建议至少建立 2 个工作空间，例如一个“正式汇报”用于职场演示文稿，另一个“个人创作”用于读书笔记、知识卡片与灵感速记。
- **沉淀个人专属风格**：在常用空间中维护一套自己惯用的主色调、字体族与核心封面组件，后续每次新建演示文稿均可直接复用，大幅减少重复设计。

### 5.2 团队协作流通
- **设计标准母版并分发**：主创或设计人员可在自己的工作空间中配置好团队官方主题、色板、字体与通用组件（如“团队介绍页”、“三列指标卡”）。
- **通过模板包分发复用**：完成设计后导出模板包（`.zip`）分发给团队其他成员，成员导入到各自的工作空间后即可基于统一规范开展内容填充，保持团队风格一致。
- **面向未来平滑过渡**：制作组件时规范化 `previewSchema` 和命名，后续同工作空间成员共享功能上线后，可无缝平滑迁移至多人实时协作模式。
