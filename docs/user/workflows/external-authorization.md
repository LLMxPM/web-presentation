# 管理 ChatGPT 外部授权

此流程用于管理员已启用远程 MCP OAuth 的环境。首批目标为 ChatGPT 网页端；实际远程 MCP 服务和 ChatGPT 连接仍需管理员完成部署与联调。未启用的环境会在“外部授权”页显示服务关闭状态。

## 连接时确认范围

1. 从 ChatGPT 发起平台连接，进入平台登录页；完成登录后返回“连接 ChatGPT”确认页。
2. 核对当前账户和连接服务，勾选至少一个允许访问的工作空间。
3. 核对请求的能力。读取能力默认选中；创建、修改、归档和执行任务需要勾选对应的管理能力。您可以取消不需要的权限。
4. 点击“授权并返回 ChatGPT”。不希望连接时点击“拒绝”。

授权只包含本次选择的具体空间。新增空间不会自动加入授权；失去空间成员资格后，相应授权会失效。请求过期时请返回 ChatGPT 重新发起连接。

## 查看与撤销

打开“设置与管理 → 个人设置 → 外部授权”，查看客户端、工作空间、能力及授权时间。点击对应授权的“撤销”，确认后整条授权失效。

撤销后，客户端需要重新获得授权才能继续使用相应权限。已经接受的后台任务会继续执行；需要停止任务时，使用任务本身的取消入口。
