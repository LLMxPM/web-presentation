# 自动放映与翻页配置

本文说明如何为项目设置翻页动画和自动放映，以及从 Editor 进入放映后的控制方式。平台支持单窗口定时放映、本页内容完成后翻页，以及演讲者双窗口放映；无人值守长期放映尚未开放。

放映以「全屏即放映」为唯一模型：非全屏只是预览，根元素全屏才开始本次放映。页面内的动画、旁白与自动视频由页面的 Scene 显式登记，放映只按真实完成推进，不提供暂停、定位或任意时刻重建。

## 1. 配置项目默认值

1. 打开项目的页面列表，在顶部工具栏点击 **项目设置**，切换到 **放映** 分区。
2. 在 **翻页动画** 区域设置：
   - **动画效果**：无动画、淡入淡出或推入。推入翻回上一页时方向自动反转。
   - **动画时长（秒）**：无动画固定为 0 秒且不可编辑；其他效果可设置 0.1～2 秒。
3. 在 **翻页方式** 区域设置：
   - **翻页模式**：手动翻页、定时翻页、本页完成后翻页。
     - 手动翻页：等待用户操作，不会自动翻页。
     - 定时翻页：过渡与资源就绪后计时，到点翻页并停止本页未完成的播放。
     - 本页完成后翻页：本页有限动画、旁白和视频实际完成后再翻页；循环装饰不参与等待。页面没有可用的完成目标时，放映控制条会提示配置错误。
   - **停留时长（秒）**：仅定时翻页可设置，1 秒～1 小时。
   - **完成后停留（秒）**：仅本页完成后翻页可设置，0 秒～1 小时；0 表示完成后立即翻页。
   - **到达末页后循环放映**：开启后末页回到第一个可放映页面；关闭时末页停留并显示已结束。
4. 点击 **保存配置**。配置会写入项目默认值，不影响页面源码，也不会创建页面变更任务。

只有当前服务端声明的模式才会出现在下拉中；服务端未声明「本页完成后翻页」时表单会提示检查服务版本，不会静默改成其它模式。

浏览器要求全屏请求由用户手势触发。请在 Runtime 窗口中点击 **进入放映**（或按 `F`）；进入全屏即开始本次放映，退出全屏即结束放映并回到预览。按 `F11` 或使用浏览器菜单全屏只是把窗口放大，不会进入放映，也不会开始自动推进。

## 2. 设置旁白与音效

在资源库上传音频后，打开项目 **项目设置 → 音频**，调整主音量、旁白音量和音效音量，并按需绑定前进、后退或 `interaction.*` cue。保存后重新进入放映，才能让新快照使用更新后的绑定。

页面旁白由页面中的 `AssetAudio.v1` 以 `purpose="narration"` 引用音频资源，并由页面 Scene 用 `createSceneMediaTask.v1` 显式接管，实际播放结束才算完成；页面交互音效由 `useAudioCue.v2` 触发，只等待真实播放许可回执。自动视频使用 `AssetVideo.v1` 的 `purpose="automatic"`；`purpose="content"` 的媒体只由用户手动播放，放映不会自动接管。同一页最多一个自动发声主媒体，其余自动视频必须静音。

旁白和 cue 在实际放映时播放；普通预览、截图和静态 PDF/PPTX 导出不会自动播放。浏览器阻止自动播放时，放映会进入「等待页面恢复」，需要在放映窗口本窗口点击允许播放；Editor 或演讲者控制台的点击不能代替该窗口的手势，全屏成功也不保证发声成功。

## 3. 为单页覆盖默认值

1. 在 **已加入路由** 分区点击 **页面结构**，打开页面与放映顺序。
2. 点击目标页面行，在右侧检查器的 **放映** 区域勾选 **覆盖翻页动画** 或 **覆盖翻页方式**，填写该页的值；未勾选的项目继承项目默认值。
3. 修改会在草稿中立即生效，点击底部 **保存页面结构** 后写入项目。点击 **恢复继承** 会清除该页覆盖，重新使用项目默认值。

覆盖按整组生效：勾选「覆盖翻页动画」后，效果和时长一起写入；清除时整组恢复继承。两组覆盖互相独立，恢复其中一组不会影响另一组。分组不能单独覆盖，组内页面各自设置；选中分组后点击 **批量设置本章** 可以统一修改本章子页。

页面结构顶部会显示项目默认放映摘要和预计总时长。预计时长只累加翻页过渡、定时停留与完成后停留；本页完成模式的实际播放时长与手动页的等待时间不计入。隐藏页不显示在目录，也不参与自动或手动翻页。

## 4. 进入放映

- 在页面列表或页面详情点击 **放映**，会打开 Runtime 预览；在 Runtime 窗口点击右上角 **进入放映**（或按 `F`）后请求全屏，并开始本次放映。
- 在 **页面结构** 中选中页面后，点击检查器底部的 **保存并从这里放映**（选中分组时为 **保存并从本章放映**），会先保存整棵页面结构，再按该页生成新的只读快照；进入 Runtime 预览后同样需要点击 **进入放映**。
- 非全屏状态只是预览：保留侧栏、缩略图、卡片、导出和翻页按钮，不启动任何自动计时，也不执行页面 Scene。
- 进入全屏后只保留画布和一条放映控制条；侧栏、缩略图、导出和预览翻页按钮隐藏。
- 退出全屏即结束本次放映并返回预览，当前页保持不变；页面 Scene 与媒体任务立即停止并清理，不保留后台推进。
- 浏览器拒绝全屏时留在预览并显示提示，不会降级为窗口放映。
- 每次放映都会生成一个新的只读快照；已经打开的放映窗口不会自动更新，修改配置后需要重新进入放映。
- 在预览工具栏或放映控制条点击 **演讲**（或按 Shift+P）会打开演讲者控制台和观众窗口。观众窗口是唯一放映和推进者；主窗口变为控制台，只发送有限意图并回显观众窗口的原子状态。
- 从预览或放映控制条进入演讲时，本窗口都会先停止自己的播放；观众窗口按各页配置重新建立放映。

页面详情只有在页面已加入项目路由时才显示 **放映** 入口；未加入路由的页面不提供放映。

## 5. 放映中的控制

- 控制条包含：上一页、保持本页/释放本页、下一页、页码、状态、剩余时间、静音、演讲和退出；页面失败时追加 **重试当前页**，末页结束后追加 **重新开始**。
- 控制条默认收起，鼠标移到窗口底部时显示，移开即隐藏；保持、错误、等待恢复或已结束状态会保持显示，方便重试或退出。
- 状态取自当前页的真实放映事实：已停止、准备中、放映中、等待页面恢复、错误、已结束；窗口切到后台时显示后台暂挂。
- 剩余时间按模式显示：定时翻页显示剩余秒数，手动翻页显示「本页手动」，本页完成模式在完成前显示「等待完成」，保持时显示「保持当前页」，停止或结束后显示「—」。
- **翻页键**：`→`、`↓`、`PageDown`、`空格` 下一页；`←`、`↑`、`PageUp` 上一页。放映态不再把空格留给播放层，空格与方向键统一按下一页处理。手动模式末页不会绕回首页。焦点停在按钮或链接上时，空格保留按钮的原生激活，不触发翻页。
- **跳页键**：`Home` / `End` 跳到第一页 / 最后一页；数字键跳到对应页码。总页数超过 9 时支持两位数字，连续输入后约 0.6 秒生效；页码不存在时给出行内提示。
- 预览状态另有：`O` 打开卡片模式，`F` 进入放映，`Shift+P` 打开演讲者模式；放映状态保留 `Shift+P`。输入框、文本域和可编辑区域内的按键不会被拦截。
- **保持本页 / 释放本页**：保持只抑制自动翻页，页面动画、旁白与视频继续播放，不暂停 Scene，也不改写项目配置；释放后按当前页模式重新计算停留。
- **静音**：只切换当前放映窗口的总静音，不改变「同页最多一个自动发声主媒体」的约束，也不影响其它窗口。
- 配置为手动翻页的页面在任何会话中都等待用户操作，剩余时间显示「本页手动」。
- 本页完成模式下，只有有限任务真实完成才推进；无限装饰不阻塞。页面没有完成目标、任务失败或媒体加载失败时，控制条显示有界错误，可重试当前页或手动翻页；错误摘要不包含资源地址或浏览器堆栈。
- 定时翻页到点即翻页，并停止本页尚未完成的任务。
- 末页且未循环时显示「已结束」，可重新开始或退出。
- 切换到后台标签页或窗口会暂停计时与页内任务的有效推进，切回后继续，不补跳后台期间积压的推进。
- 卡片模式或缩略图预览不会启动后台自动推进；退出卡片模式后保持停止状态。

### 演讲者双窗口

- 观众窗口必须先进入全屏才能开始放映；未全屏时控制台显示「等待观众窗口全屏」，开始放映的请求会被拒绝并提示先在观众窗口进入全屏。
- 观众窗口是唯一调度者：控制台只发送开始、停止、下一页、上一页、导航、保持、释放、重试和关闭这些有限意图，收到观众窗口回传的原子状态后才更新页码与预览，不自行建立第二份播放进度。
- 控制台状态区显示：未开始、准备中、放映中、受阻、失败、已结束、观众窗口已关闭，以及保持时的「保持当前页，页内播放继续」。受阻时提示在观众窗口点击允许播放。
- 观众窗口是只读画面，不响应本地翻页快捷键；请在控制台使用传输栏。控制台键盘不受观众窗口是否全屏限制。
- 关闭观众窗口后控制台显示等待；点击 **观众窗口** 会复用已打开的窗口，只有窗口确实关闭后才重新打开。重新打开的观众窗口按各页配置初始化，不继承此前临时的保持状态。
- 较新的观众窗口接管后，旧窗口停止播放；重复投递、旧修订和旧协议消息一律被丢弃，不会覆盖较新状态。
- 演讲者窗口本身不自动播放页面媒体；媒体许可重试必须来自观众窗口的本地手势。

## 6. 边界与已知限制

- 定时器从页面就绪且翻页过渡结束后开始计时。页面加载失败、资源未就绪或浏览器阻止播放时，控制条会显示错误或等待恢复状态，可重试或手动翻页。
- 本页完成模式只等待页面 Scene 显式登记的有限任务；循环装饰、第三方 iframe 播放器、Web Audio 和页面脚本自行创建且不登记的媒体不参与完成判定。
- 截图、缩略图、PDF、PPTX 和打印使用独立的静态呈现：页面必须显式声明可读默认态、独立海报或明确不可呈现，捕获不会推进 Scene、不发声、不推进模型动作，也不提供任意时刻取帧。内容没有可用静态态时返回不可呈现且不可重试；批量导出会整体失败并指出页码，不静默缺页。
- 自动放映只影响放映窗口，不会操纵其他正在运行的浏览器；CLI 保存放映配置也不等于远程控制播放。
- 直接打开构建产物链接默认是预览，不会自动全屏或自动推进；无人值守场景需要在 Runtime 窗口内点击进入放映，或使用另行设计的 kiosk/自动化入口。
- 页面内的视频、图表等元素全屏时，本次放映不会结束，也不会自动暂停页面推进；退出该元素全屏后，浏览器通常不会恢复整个页面的全屏，会按退出全屏处理并结束本次放映。需要继续时请重新点击 **进入放映**。

### 支持状态

以下区分「目标支持但尚待实机验收」与「明确未验证/不支持」，实机结论由收敛工作包 C3 回填，本文不提前声明已支持。

- **目标支持，待实机验收**：桌面 Chromium 单窗口放映、同浏览器双窗口演讲模式、Runtime 根元素全屏、独立构建产物放映、三种翻页模式、旁白与 cue 发声、三维动作正向播放、受保护媒体缓冲恢复、30 分钟以上长稳。工程与开发回归已完成，真实浏览器、远程 Renderer、生产镜像与独立产物证据尚未取得。
- **明确未验证，不作支持承诺**：观众窗口多屏授权（使用当前窗口全屏回退不等于多屏授权通过）、Firefox 与 WebKit、移动端与行内播放、操作系统真实睡眠与恢复。
- **明确不支持**：暂停/继续播放、定位到指定时刻、指定状态截图、任意时刻状态重建、历史版本混跑与自动降级。这些能力已永久移除，不会以兼容开关形式恢复。
- 无人值守长期放映尚未开放，需要独立代理服务与专项长稳验收。

## 7. 用 CLI 配置

CLI 使用 `wp project slideshow get/update` 读写项目默认值，使用 `wp project route update` 修改页面结构与逐页覆盖，使用 `wp project audio get/update/clear` 维护项目音量与 cue 绑定。字段语义与 Editor 一致：完整对象写入、显式 null 恢复继承、只读生效值 `effective_slideshow` 不得回写。具体命令以 CLI 当前帮助为准。
