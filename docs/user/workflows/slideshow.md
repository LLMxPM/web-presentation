# 自动放映与翻页配置

本文说明如何为项目设置翻页动画和定时自动放映，以及从 Editor 进入单窗口放映后的控制方式。当前只支持单窗口定时放映；媒体结束翻页、演讲者双窗口和无人值守长期放映尚未开放。

## 1. 配置项目默认值

1. 打开项目的页面列表，在顶部工具栏点击 **样式**，打开“项目展示配置”。
2. 在 **自动放映** 区域设置：
   - **动画效果**：`none`、`fade` 或 `push`。`push` 翻回上一页时方向自动反转。
   - **动画时长**：`none` 必须为 0 秒；其他效果可设置 0.1～2 秒。
   - **翻页模式**：手动翻页或定时翻页。手动模式保留停留时长，但不会自动翻页。
   - **停留时长**：定时模式下当前页就绪且过渡结束后的等待时间，可设置 1 秒～1 小时。
   - **循环放映**：末页后回到第一个可放映页面。
   - **预览时自动开始**：进入放映入口后自动开始计时。
3. 点击 **保存配置**。配置会写入项目默认值，不影响页面源码，也不会创建页面变更任务。

浏览器可能要求用户先与页面交互才允许自动播放或全屏。若自动开始未生效，直接点击控制条的开始按钮即可。

## 2. 为单页覆盖默认值

1. 在项目路由配置表中找到目标页面，点击 **放映**。
2. 分别勾选 **覆盖翻页动画** 或 **覆盖翻页方式**，填写该页的值；未勾选的项目继承项目默认值。
3. 点击 **应用** 保存。点击 **恢复继承** 会清除该页覆盖，重新使用项目默认值。

覆盖按整组生效：勾选“覆盖翻页动画”后，效果和时长一起写入；清除时整组恢复继承。分组不能单独覆盖，组内页面各自设置。

## 3. 开始放映

- 在页面列表点击 **放映**，从首页开始。
- 在页面详情点击 **放映**，选择 **从首页放映** 或 **从当前页放映**。
- 每次放映都会生成一个新的只读快照；已经打开的放映窗口不会自动更新，修改配置后需要重新进入放映。

当前页入口只对已挂载且可见的页面生效。隐藏页面不参与自动或手动翻页序列。

## 4. 放映中的控制

- 控制条显示当前页码、状态和剩余停留时间；按钮提供开始、暂停、继续、重试和停止。
- **空格**：暂停或继续放映。输入框内、组合键和按键长按不会触发。
- **方向键 / PageUp / PageDown**：全屏放映时切换上一页或下一页；末页手动前进不会绕回首页。
- **停止**：保留当前页面并结束本次调度；再次点击开始会从当前页重新计时。
- 切换到后台标签页或窗口会暂停计时，切回后不会自动继续，也不会补跳；需要手动点击继续。
- 卡片模式或缩略图预览不会启动后台自动推进；退出卡片模式后保持停止状态。

## 5. 边界与已知限制

- 定时器从页面就绪且翻页过渡结束后开始计时。页面加载失败或浏览器阻止播放时，控制条会显示错误或受阻状态，可重试或手动翻页。
- 自动放映只影响放映窗口，不会操纵其他正在运行的浏览器；CLI 和 MCP 保存放映配置也不等于远程控制播放。
- 当前不宣传也不支持媒体结束翻页、演讲者/观众双窗口同步和无人值守长期放映；前两项按后续阶段验收开放，无人值守长期放映依赖独立代理服务，均尚未开放。
- 截图、PDF、PPTX 和打印使用独立捕获上下文，不会启动自动放映或推进主窗口。

## 6. 用 CLI 或外部 Agent 配置

CLI 使用 `wp project slideshow get/update` 读写项目默认值，使用 `wp project route update` 修改路由覆盖；MCP 通过 `wp_update_entity` 的 `action=configuration` 与 `action=route_tree` 完成同样操作。字段语义与 Editor 一致：完整对象写入、显式 null 恢复继承、只读生效值 `effective_slideshow` 不得回写。具体命令以各仓当前帮助为准。
