# 用户工作流

本组是用户日常操作的主线，按“我要完成什么”组织。每篇文档优先说明前置条件、操作顺序、完成后的检查点和常见风险；能力原理请看[平台特性](../features/README.md)。

| [项目与页面](./project-and-page.md) | 创建项目、低代码可视化面板、源码编辑、版本与双模协作 |
| [资源管理](./resources.md) | 资源类型、可编辑内容、元数据、替换、归档、删除和引用关系 |
