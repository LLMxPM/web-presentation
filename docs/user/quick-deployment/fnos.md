# 飞牛 fnOS 快速部署

本页指导如何通过国产 NAS 系统 **飞牛 fnOS** 的可视化 Docker 容器套件进行极简部署。`sqlite-lite` 为**单容器架构**，内置 Backend、Editor、Runtime、Renderer（含 Chromium 浏览器）与 Nginx Gateway，**无需任何必填环境变量，无需 secret 密钥文件，也无需启动任何辅组容器**。

## 1. 打开 Docker 套件并拉取镜像

1. 在 fnOS 桌面打开 **Docker 管理器**（或应用中心内的容器管理器）。
2. 点击左侧导航栏的 **“镜像”**（或“镜像仓库”）。
3. 在搜索栏输入 `llmxpm/web-presentation`。
4. 找到目标镜像，点击 **“拉取”**，选择标签 `sqlite-lite`。
5. 等待下载完成，镜像将出现在“本地镜像”列表中。

## 2. 准备持久化存储目录

通过 fnOS 的“文件管理”或在 Docker 管理器中创建数据目录：
1. 打开 **文件管理**，在存储池（如 `/vol1/1000/docker/`）下创建文件夹 `web-presentation`。
2. 在其下方创建子文件夹 `data`，完整路径形如 `/vol1/1000/docker/web-presentation/data`。
3. 该目录用于保存 SQLite 数据库、上传资产、自动持久化的加密密钥和截图文件。

## 3. 创建与启动容器（零必填变量）

1. 在 Docker 管理器的“本地镜像”中选中 `llmxpm/web-presentation:sqlite-lite`，点击 **“创建容器”**。
2. **基础设置**：
   - **容器名称**：填写 `web-presentation`。
   - **重启策略**：选择“除非手动停止”或“始终重启”。
3. **网络与端口**：
   - 模式选择默认的“网桥（Bridge）”。
   - 端口映射：主机端口填写 `8080`（如被占用可改 `18080`），容器端口填写 `80`，协议为 `TCP`。
4. **存储路径（卷）**：
   - 点击“添加路径映射”，选择刚才创建的本机目录（如 `/vol1/1000/docker/web-presentation/data`）。
   - 容器路径填写：`/app/backend/data`。
   - 读写模式保持默认的“读写”。
5. **环境（变量）**：
   - **新手或极简体验可完全留空！** 平台所有密钥（含 AI 凭据 Fernet 密钥）与内部通信凭证均由系统启动时自动生成并持久化保存在上述数据文件夹中。
   - 若希望局域网其它设备访问飞牛（假设飞牛局域网 IP 为 `192.168.1.20`），可按需添加以下 3 个外部入口变量：
     - `BACKEND_PUBLIC_BASE_URL` = `http://192.168.1.20:8080`
     - `RUNTIME_PUBLIC_BASE_URL` = `http://192.168.1.20:8080/runtime`
     - `CORS_ORIGINS` = `["http://192.168.1.20:8080"]`
6. 点击“完成”，系统将自动创建并启动容器。

## 4. 获取管理员密码并登录

1. 在容器列表中点击 `web-presentation`，进入详情页面。
2. 查看 **“日志”**，在初次启动的日志中即可看到如下管理员密码信息：
   ```text
   ====================================================================
   [Lite 首启提示] 已为平台管理员账号 (admin) 自动生成初始随机密码：
          <一串随机字符>
   请保存此密码，并在登录后尽快通过系统设置修改管理员口令。
   ====================================================================
   ```
3. 打开浏览器访问 `http://飞牛IP:8080`，输入用户名 `admin` 和该随机密码即可登录。
4. 登录后可进入右上角「系统设置」修改管理员密码。

## 5. 日常维护与数据备份

- **日常升级**：在本地镜像中拉取最新版 `sqlite-lite`，停止并删除旧容器后使用相同的数据目录重新创建容器即可，数据完全无损保留。
- **数据备份**：定期备份创建的 `data` 目录即可保护全部演示文稿、素材与凭据。
- 更多日常运维和反向代理排障技巧，请阅读 [SQLite 单体版日常维护指南](./maintenance.md)。
