# 群晖 DSM 快速部署

本页指导如何通过群晖 DSM 的 **Container Manager** 图形界面进行极简部署。已发布的 `sqlite-lite` 为**单容器架构**，内置了 Backend、Editor、Runtime、页面截图浏览器（Chromium）与 Nginx Gateway，**无需配置任何必填环境变量，无需 secret 密钥文件，也无需启动第二个渲染容器**。

## 1. 拉取镜像

1. 打开群晖 DSM，进入 **Container Manager**。
2. 在左侧导航点击 **“注册表”**，搜索栏输入 `llmxpm/web-presentation`。
3. 选中结果，点击 **“下载”**，在标签列表中选择 `sqlite-lite`。
4. 等待下载完成，镜像将显示在 **“映像”** 列表中。

## 2. 准备数据存储目录

在 DSM 的 **File Station** 中创建持久化目录：
1. 打开 **File Station**，在 `docker` 共享文件夹下新建文件夹 `web-presentation`。
2. 在 `web-presentation` 下再新建一个子文件夹 `data`，完整路径为 `/docker/web-presentation/data`。
3. 系统数据库、上传图片、自动生成的加密密钥和页面截图都将保存在此目录下。

## 3. 创建与启动容器（零必填变量）

1. 回到 Container Manager，进入 **“映像”** 页面，选中 `llmxpm/web-presentation:sqlite-lite`，点击 **“运行”**。
2. **常规设置**：
   - **容器名称**：填写 `web-presentation`。
   - **启用自动重新启动**：建议勾选。
3. **高级设置**：
   - **端口设置**：
     - 本地端口：`8080`（若被占用可修改为 `18080`）
     - 容器端口：`80`
     - 类型：`TCP`
   - **存储空间设置**：
     - 点击“添加文件夹”，选择刚才创建的 `/docker/web-presentation/data`。
     - 装载路径填写：`/app/backend/data`。
     - 权限保持默认的“读写”。
   - **环境**：
     - **极简体验可完全留空！** 平台所有密钥（含 AI 凭据 Fernet 密钥）与内部通信凭证均由系统启动时自动生成并持久化保存在上述数据文件夹中。
     - 若希望直接从局域网内其它设备访问群晖（假设群晖局域网 IP 为 `192.168.1.30`），可按需添加以下 3 个外部入口变量：
       - `BACKEND_PUBLIC_BASE_URL` = `http://192.168.1.30:8080`
       - `RUNTIME_PUBLIC_BASE_URL` = `http://192.168.1.30:8080/runtime`
       - `CORS_ORIGINS` = `["http://192.168.1.30:8080"]`
4. 确认配置无误，点击 **“下一步”** 并完成容器创建与启动。

## 4. 获取初始管理员密码并登录

1. 在 Container Manager 的 **“容器”** 列表中，点击进入 `web-presentation` 容器详情。
2. 切换到 **“日志”** 选项卡。
3. 在首启日志中找到如下管理员密码提示：
   ```text
   ====================================================================
   [Lite 首启提示] 已为平台管理员账号 (admin) 自动生成初始随机密码：
          <一串随机字符>
   请保存此密码，并在登录后尽快通过系统设置修改管理员口令。
   ====================================================================
   ```
4. 复制该初始密码，在浏览器中打开 `http://群晖IP:8080`，使用账号 `admin` 和该密码登录。
5. 登录后点击右上角管理员头像，进入「系统设置」修改管理员密码。

## 5. 日常维护与数据备份

- **日常升级**：在 Container Manager 映像列表重新下载最新 `sqlite-lite` 映像，然后在容器列表选择“操作” -> “重置”，即可完成无损升级。
- **数据备份**：只要备份 `/docker/web-presentation/data` 目录即可完整保留数据库、上传素材和加密密钥。
- 更多日常运维和反向代理排障技巧，请阅读 [SQLite 单体版日常维护指南](./maintenance.md)。
