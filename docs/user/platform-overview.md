# 平台介绍

`web-presentation` 是面向 AI 演示文稿创作的平台，用于创作 PPT、图文卡片、专题报告页、数据解读页等视觉化内容。平台把页面内容代码化，并把资源、组件、主题和样式沉淀为可复用资产，让团队可以在同一套工作空间中持续创作、预览、迭代和交付。

## 适用场景

| 场景 | 适合产物 | 平台价值 |
| :--- | :--- | :--- |
| 演示文稿创作 | PPT 页面、演讲用页面、封面页 | 让 AI 参与结构生成、视觉改写和内容补全 |
| 报告页制作 | 数据解读页、专题报告、项目汇报页 | 复用团队主题、组件和资源，降低重复设计成本 |
| 图文内容生产 | 图文卡片、活动页、长图局部页面 | 使用 Runtime 快速预览视觉结果，按项目沉淀版本 |
| 团队资产管理 | 资源、组件、主题、样式 | 把素材和组件统一放进工作空间，支持跨项目复用 |

## 核心对象

| 对象 | 负责什么 | 关系 |
| :--- | :--- | :--- |
| 工作空间 | 隔离团队成员、项目和可复用资产 | 项目、资源、组件、主题、样式和字体都归属于工作空间 |
| 项目 | 组织一次演示、报告或专题内容 | 项目包含多个页面，并选择主题、样式和构建配置 |
| 页面 | 承载最终创作内容 | 页面可以引用资源、已发布组件、主题和样式 |
| 资源 | 保存图片、图标、视频、字体、图表、公式等素材 | 资源可被页面、组件、主题和字体注册复用 |
| 组件 | 沉淀可复用的 Vue 结构 | 组件以草稿和发布版本供页面稳定引用 |
| 主题、字体与样式 | 维护团队视觉规范 | 共同影响项目和页面的视觉表达 |

AI 会话围绕当前用户有权访问的工作空间、项目、页面、组件或资源展开；Runtime 则负责预览、截图和构建。两者是平台能力，不是用户需要单独维护的创作对象。

对象之间可以简单理解为：

`工作空间` → `项目` → `页面` → `预览 / 截图 / 构建`

同时，`资源 / 组件 / 主题 / 字体 / 样式` 为项目和页面提供可复用能力。

具体操作统一收录在[常用工作流](./workflows/README.md)：[资源管理](./workflows/resources.md)、[组件管理](./workflows/components.md)和[主题、字体与样式](./workflows/design-system.md)。

## 平台组成

| 模块 | 用户看到的能力 | 说明 |
| :--- | :--- | :--- |
| Editor | 创作工作台 | 管理项目、页面、资源、组件、主题、样式和 AI 侧边栏 |
| Backend | 平台控制面 | 保存数据、校验权限、组织 AI 上下文、管理预览和构建任务 |
| Runtime | 预览与构建引擎 | 渲染页面、生成截图、执行诊断和构建 |
| 部署环境 | 私有化运行 | 通过平台镜像、Runtime 镜像和 compose 模板部署到自有环境 |

## 什么时候适合使用

如果你要持续制作多页内容、复用团队资产，或希望让 AI 在项目上下文中持续迭代，`web-presentation` 会更适合。若只是一次性生成一个 PPTX 文件，传统演示文稿工具或专门的文件生成工具可能更直接。

理解平台对象后，直接进入 [用户快速上手](./getting-started.md)。
