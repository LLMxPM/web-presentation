# 设置与管理

平台通过统一的「设置与管理」中心提供个人偏好、安全设置和平台管理入口。

**入口**：点击右上角用户头像，选择 **「设置与管理」**。

---

## 1. 个人设置

所有登录用户均可访问以下设置。

### AI 设置（`/settings/account/ai`）

管理聊天模型供应商、凭证配置和内容助手绑定。包括：

- 添加和管理 **聊天模型** 供应商（如 DeepSeek、硅基流动、阿里云百炼等）。
- 添加和管理 **图片生成** 服务（如 DashScope Image、OpenRouter Image）。
- 将模型绑定到 **内容助手**（主模型、图片理解、图片生成）。
- 配置推理模式（跟随模型 / 显式强度）。
- 自定义代码规范（页面规范与组件规范）。

详细操作见 [模型接入与 AI 设置](../ai/model-settings.md)。

### 访问令牌（`/settings/account/tokens`）

创建和管理 Personal Access Token (PAT)，用于 `wp` CLI 和外部 Agent（如 Cursor、Claude 等）接入平台。

- 创建令牌时选择过期时间和权限范围。
- 令牌创建后只展示一次完整值，请妥善保存。
- 可随时吊销不再使用的令牌。

### 账户安全（`/settings/account/security`）

- **修改密码**：输入当前密码和新密码完成更改。
- **查看角色**：显示当前账号的平台角色（`platform_admin` 或 `workspace_user`）和账号状态。

---

## 2. 平台管理

以下功能仅对 **平台管理员**（`platform_admin`）可见。

### 用户管理（`/settings/platform/users`）

- **创建用户**：指定用户名、姓名、初始密码和平台角色。
- **重置密码**：为忘记密码的用户设置新密码。
- **禁用 / 启用账号**：禁用后该用户无法登录，但历史资产保留。
- **搜索与筛选**：按用户名、姓名搜索，按角色和状态筛选。

> [!NOTE]
> 管理员无法禁用自身账号，也无法将自身角色降级为普通用户，确保平台始终保留至少一个可操作的管理员。

### AI 管理（`/settings/platform/ai`）

查看与管理平台级 AI 智能体配置，包括内容助手描述、提示词和工具说明。

### 系统设置（`/settings/platform/settings`）

在 Web UI 中管理平台运行配置，修改后热生效，无需重启容器。配置分为五组：

| 分组 | 说明 |
| :--- | :--- |
| 存储 | 资源存储驱动（本地 / S3）和 S3 连通性测试 |
| 常规 | 应用时区、站点标题等基础配置 |
| 安全 | 会话策略与安全相关设置 |
| AI 运营 | AI 全局开关、模型目录同步和超时设置 |
| 诊断 | 运行时日志级别调整和 HTTP trace 开关 |

> [!IMPORTANT]
> 被环境变量覆盖的配置项会在 UI 中显示锁定图标，表示该值由部署配置控制，不能在 Web UI 中修改。如需紧急修复错误的数据库配置，可通过环境变量覆盖后重启容器。

## 3. 旧版路径

以下旧路径会自动重定向到新的设置中心：

| 旧路径 | 新路径 |
| :--- | :--- |
| `/account/ai-settings` | `/settings/account/ai` |
| `/admin/users` | `/settings/platform/users` |
