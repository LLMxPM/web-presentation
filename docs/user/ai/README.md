## 当前助手

平台只提供一个工作空间级内容助手，通过固定通用工具处理项目、页面、组件、资源、主题和样式。需要隔离处理复杂子任务时，助手会委派给自己的子运行，用户无需切换助手、会话或页面。

## 使用原则

- 先描述目标，再给素材和限制。
- 修改已有页面时说明范围，避免让 AI 猜测。
- 工具确认前检查对象、参数和影响范围。
- 对视觉结果不满意时，给出具体反馈，例如“减少装饰元素”“提高标题层级”“压缩信息密度”。
