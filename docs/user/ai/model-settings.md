# 模型接入与 AI 设置实战

在私有化部署环境下，平台不绑定任何单一商业闭源服务，用户可以使用个人或团队采购的 API Key 自由接入主流大语言模型和图像生成服务。

进入设置：点击右上角用户头像，在菜单中选择 **“AI 设置”**（路径 `/account/ai-settings`）。

---

## 1. 架构理解：聊天模型与图片生成相互独立

在配置前，请务必了解平台的双通道设计：

```
[ 账号 AI 设置 ]
   ├── 聊天模型 (Chat / Text)   ──> 负责对话理解、生成 Vue 代码、分析大纲与工具调用
   └── 图片生成 (Image Gen)    ──> 负责根据提示词生成全新视觉素材并存入资源库
```

- **两套凭证完全隔离**：你在“聊天模型”中填写的 Key 不会自动同步给“图片生成”。即使是同一家服务商（如 OpenAI、阿里云或 OpenRouter），也必须分别在两侧创建供应商并录入各自的连接配置。

---

## 2. 国内主流聊天模型接入指南

平台支持 Models.dev 内置目录服务商，也支持标准的 **OpenAI-compatible（兼容协议）** 自定义接入。对于国内私有化部署，推荐以下高性价比服务：

### 2.1 方案 A：DeepSeek 官方 API
DeepSeek 在代码生成与逻辑推理上表现极佳，且成本低廉，是小团队的首选：
- **供应商类型**：选择自定义 `OpenAI-compatible`。
- **Base URL**：`https://api.deepseek.com/v1`（必须带 `/v1`）。
- **API Key**：填入你在 DeepSeek 开放平台申请的 `sk-xxxxxxxx`。
- **常用模型 ID**：
  - `deepseek-chat`（即 DeepSeek-V3，响应迅速，极度擅长编写页面与组件代码）；
  - `deepseek-reasoner`（即 DeepSeek-R1 深度推理模型，适合处理复杂大纲策划与版式推导）。

### 2.2 方案 B：硅基流动 (SiliconFlow)
国内知名模型聚合托管平台，提供稳定的 DeepSeek 与 Qwen 系列开源模型直连：
- **供应商类型**：选择自定义 `OpenAI-compatible`。
- **Base URL**：`https://api.siliconflow.cn/v1`。
- **API Key**：填入硅基流动控制台生成的密钥。
- **常用模型 ID**：
  - `deepseek-ai/DeepSeek-V3`
  - `deepseek-ai/DeepSeek-R1`
  - `Qwen/Qwen2.5-72B-Instruct`

### 2.3 方案 C：阿里云百炼 (DashScope)
- **供应商类型**：选择内置 `DashScope` 或 `OpenAI-compatible`。
- **Base URL**：`https://dashscope.aliyuncs.com/compatible-mode/v1`。
- **常用模型 ID**：`qwen-plus`、`qwen-max`、`qwen-turbo`。

## 3. 独立图片生成服务接入指南

内容助手支持在对话中直接画图并自动存入工作空间资源库。图片服务需要在左侧切换到 **“图片生成”** 面板单独配置：

### 3.1 常用生图服务商配置
- **阿里云百炼 (DashScope Image)**：
  - 供应商协议选择 `dashscope_image`；
  - Base URL：`https://dashscope.aliyuncs.com/api/v1`（必须带 HTTPS 与 `/api/v1`）；
  - 常用生图模型：`wanx-v1`（通义万相）。
- **OpenRouter Image**：
  - 供应商协议选择 `openrouter_image`；
  - 常用模型：支持按需调用各类第三方生图模型。
- **OpenAI 兼容生图**：
  - 协议选择 `openai_image`，接入 `dall-e-3` 或兼容生图网关。

> **注意**：如果图片理解和图片生成通道均未配置任何模型，聊天界面中的图片上传入口将置灰禁用。

---

## 4. 绑定到“内容助手”

添加完模型之后，必须将其绑定到平台核心智能体才能生效：

1. 在 AI 设置左侧导航点击 **“内容助手”**。
2. 切换到 **“模型配置”** 标签页。
3. **聊天主模型**：从已添加的聊天模型列表中选择你绑定的模型（如 `deepseek-chat`）。
4. **图片理解模型**：选择支持 Vision 视觉能力的模型（如 `deepseek-chat`、`gpt-4o` 或多模态模型）。
5. **图片生成服务**：选择先前在生图通道中配置的生图模型。
6. 点击“保存生效”。

## 5. 推理强度与 Token 预算调节

在内容助手的模型高级设置中，你可以进一步微调运行策略：

### 5.1 推理模式（针对支持 Reasoning 的模型）
- **跟随模型**：默认行为，保持服务商原生逻辑；
- **显式强度**：针对 DeepSeek-R1 等模型，可指定推理强度：
  - `快速 (low)`：压缩思考步数，适合日常轻量修改；
  - `均衡 (medium)`：平衡生成质量与延迟；
  - `深入 (high)` / `极致 (max)`：适合从零规划多页复杂汇报大纲。

### 5.2 上下文与预算控制（省 Token 技巧）
- **平台可用输入窗口**：建议根据小团队预算配置（例如 64K ~ 200K）。平台内置历史自动压缩机制（预留 32K 触发，自动压缩为 16K 核心摘要），确保多轮长会话不会超出模型物理上下文，同时大幅减少昂贵的重复上下文消耗。
- **单次请求输出上限**：系统默认封顶 32K，保障长页面代码能够一次性完整生成不截断。

## 6. 自定义代码规范 (Code Standards)

在内容助手的 **“代码规范”** 标签页中，团队管理员可以定义 AI 生成代码时的硬性设计法则：
- **页面规范 (`page`)**：约束 AI 生成 Vue SFC 页面时的布局、栅格、配色变量引用与可用组件；
- **组件规范 (`component`)**：约束组件的 props 声明格式与 previewSchema 示例规范；
- 管理员可随时修改 Markdown 规则并保存，也可一键“恢复默认”清除定制。
