# 模型能力与推理设置

账号 AI 设置把模型能力和回答策略分开展示，避免把供应商技术参数直接暴露为普通配置。

## 推理模式

- **跟随模型**：不覆盖模型默认推理行为，适合大多数场景。
- **关闭推理**：只在平台确认模型支持显式关闭时可选。
- **指定强度**：选择快速、均衡、深入或极致。

四档对应平台值 `low / medium / high / max`。极致表示使用该模型可用的最高档，不保证供应商原始参数也叫 `max`，并可能显著增加延迟和成本。界面会显示最终生效值。

## Token 能力

- **平台可用输入窗口**：平台允许一次请求实际使用的最大输入，由你直接填写。
- **单次请求输出上限**：平台固定为 32K；若内置档案确认模型输出上限更低，会自动降低。
- **运行预留**：固定为 32K，用于提前触发历史压缩。
- **压缩摘要目标**：固定为 16K。

界面会反向计算模型最低总上下文要求：`平台可用输入窗口 + 实际输出上限`。例如填写 200K 时，模型至少需要支持 232,768 tokens 总上下文，历史约达到 167,232 tokens 时开始压缩。

已收录模型会显示“支持”或“不满足”，不满足时不能保存。未收录模型默认填写 200K 可用输入并标记“未验证”，仍允许保存；请自行确认供应商模型至少支持界面显示的最低总窗口。模型最大输出不是用户配置项，高级 JSON 也不能重复覆盖推理、输出、预留或压缩预算。
