# 能力边界

## 内容助手

内容助手在当前工作空间内处理项目、页面、组件、资源、主题和样式。一个会话可以显式指定不同项目或页面，无需切换页面或重建会话；每次操作仍会校验权限和工作空间归属。它适合生成页面初稿、改写内容、解释页面代码、维护主题文本与色板和调整视觉层级，但不承担账户认证、生产运维、部署、环境或密钥管理。

内容助手只能归档和恢复对象，不具备永久删除能力。主题修改只涉及 key、名称、说明和颜色配置，不会修改 Logo 或字体；Runtime Kit 与字体配置只读。

## 组件与资源能力

组件和资源不再由独立助手管理。内容助手通过同一组通用工具生成组件草稿、调整 previewSchema、发布组件、识别或生成图片、维护 SVG 与内容资源；目标 ID 和工作空间归属在每次调用时重新校验。复杂任务可以委派给内容助手自己的隔离子运行，但不会切换身份或扩大权限。

## 可见性边界

AI 只能基于当前用户有权访问的工作空间、项目、页面、组件和资源工作。工具确认并不等于权限放开，所有写入仍应经过 Backend 权限校验。
