# 工具确认与会话

## 工具确认

AI 调用会影响平台数据的工具时，可能需要用户确认。确认前应重点检查：

- 操作对象是否正确。
- 参数是否符合预期。
- 是否会覆盖、删除或批量修改内容。
- 是否引用了正确的项目、页面、组件或资源。

低风险查询类工具通常可以直接运行；写入、删除、发布、构建等操作应谨慎确认。

## 会话范围

会话通常绑定当前工作空间、项目、页面、组件或资源。切换对象后，AI 看到的上下文会变化。需要跨对象操作时，应在提示词里明确说明来源和目标。

## 图片附件

用户上传图片后，消息区会持续展示附件，但内容模型只收到附件 ID 和文件名、类型、大小等轻量信息，不会直接收到图片像素。需要看图时，内容助手会单次调用“图片理解”工具；需要生成或编辑图片时，会创建后台图片任务。两个视觉调用都不继承整段对话历史。

内容助手和资源助手都可以调用图片理解与图片生成工具。资源助手只能识别当前会话附件和工作空间图片资源，不能读取页面截图；图片生成完成后会自动保存到当前工作空间资源库，并在生成工具卡中展示。若图片理解和图片生成模型都未配置，上传入口会禁用并提示前往 AI 设置。

图片像素与图片内文字会被视为不可信内容。涉及敏感内容时，仍需确认所配置的视觉模型供应商符合团队数据政策。

## 中断和恢复

会话或 run 中断后，平台会保留运行状态、事件、消息和工具调用记录。恢复前应先确认上一轮是否已经写入数据，避免重复执行相同操作。
