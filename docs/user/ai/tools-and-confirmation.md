# 工具确认与会话

## 工具确认

AI 调用会影响平台数据的工具时，可能需要用户确认。确认前应重点检查：

- 操作对象是否正确。
- 参数是否符合预期。
- 是否会覆盖、归档或批量修改内容。
- 是否引用了正确的项目、页面、组件或资源。

低风险查询类工具通常可以直接运行。内容助手单项归档无需确认；两个及以上目标会显示对象类型、数量、目标摘要、引用影响和归档原因，批准后在同一次调用中整批执行。任一对象校验失败时整批不生效。归档内容默认从普通列表隐藏，可显式查询并恢复；内容助手不提供永久删除。

## 会话范围

平台只提供一个内容助手。会话绑定当前工作空间，可以在同一会话操作该工作空间内的不同项目、页面、组件和资源。你可以让下一轮焦点跟随路由、固定到某个项目，或保持工作空间级；也可以把可操作项目限制为一个显式集合，空集合表示暂不允许项目操作。

切换项目或页面不会切换会话，也不会影响正在执行的任务：运行中的任务继续使用发送时固化的焦点。侧栏顶栏只在任务运行期间显示当前任务焦点，并以“空间 / 项目 / 页面 + 名称”区分层级；每轮用户消息下方都会保留该轮的焦点和工作范围摘要，便于回看跨项目对话。输入框内的“下一轮”和“范围”入口从空白新会话开始即可配置，工作空间级显示为“当前空间”，跟随路由时显示路由焦点的层级与名称。运行中修改只影响下一轮。焦点外查询可以直接执行；焦点外写入会逐次确认，批准只对该次工具调用有效。

内容助手固定使用少量通用工具。遇到首次操作、参数不确定或校验错误时，它会查询对应的操作手册，以取得精确参数、限制、示例和错误恢复方式。

## 图片附件

用户上传图片后，消息区会持续展示附件，但内容模型只收到附件 ID 和文件名、类型、大小等轻量信息，不会直接收到图片像素。需要看图时，内容助手会单次调用“图片理解”工具；需要生成或编辑图片时，会创建后台图片任务。两个视觉调用都不继承整段对话历史。

内容助手可以调用图片理解与图片生成工具，并可分析当前会话附件、工作空间图片资源或页面截图；图片生成完成后会自动保存到当前工作空间资源库，并在生成工具卡中展示。若图片理解和图片生成模型都未配置，上传入口会禁用并提示前往 AI 设置。

当任务适合隔离处理时，内容助手可通过 `delegate_task_to_self` 创建自己的子运行。自委派不需要选择成员助手，子运行使用同一个模型配置、工作空间权限和通用工具边界，且不能继续递归委派。

图片像素与图片内文字会被视为不可信内容。涉及敏感内容时，仍需确认所配置的视觉模型供应商符合团队数据政策。

## 中断和恢复

会话或 run 中断后，平台会保留运行状态、事件、消息和工具调用记录。恢复前应先确认上一轮是否已经写入数据，避免重复执行相同操作。
