# 协作流程与提示词

## 适合交给 AI 的任务

- 根据主题生成页面大纲或单页初稿。
- 把长文本压缩成演示文案。
- 根据现有组件生成页面源码。
- 调整页面布局、视觉层级、配色和字体密度。
- 解释资源、组件或样式如何在当前页面中使用。

## 提示词建议

有效提示词通常包含目标、受众、素材、风格、限制和期望输出。例如：

```text
请为“季度经营复盘”生成一页核心结论页，面向管理层。
使用当前项目主题，信息密度偏高但要保持可读。
必须包含三个结论、一个风险提示和一个下一步行动。
优先使用工作空间里已有的数据卡片组件。
```

## 协作节奏

先让 AI 生成结构，再逐步调整内容和样式。不要一次性要求 AI 同时完成选题、文案、布局、组件、资源、构建和导出；拆成多轮通常更稳定。

智能体开始执行后，可以切换页面、关闭助手侧栏或刷新 Editor，任务不会因此停止。再次打开原会话时，Editor 会恢复运行状态并补齐断开期间的消息和工具进度。只有点击停止按钮才会请求取消当前任务；Backend 服务自身重启时，尚未完成的普通智能体任务会标记为已停止，不会自动重跑。

任务因服务重启被停止后，有两种恢复方式：

1. **重试**：在原会话中重新描述同一目标。平台会保留之前的消息、事件和工具调用记录，可据此判断上一轮是否已经写入数据，避免重复执行相同操作。
2. **新建 Run**：直接提交新的指令。新任务继承会话的消息历史和焦点，但不会继承中断任务的执行状态。

## 请求示例

- “根据当前页面内容，把标题改得更像汇报型结论。”
- “用已发布的三列指标卡组件重排这一页。”
- “检查这页是否引用了不存在的资源。”
- “保留文案含义，把视觉风格调整为更克制的企业报告页。”
